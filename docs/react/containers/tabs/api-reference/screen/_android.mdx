#### android.icon {#screen-android-icon}
</ReferenceHeading>

```ts
icon?: TabsScreenIconAndroid;
```

Specifies the icon for the tab bar item.

The `type` field selects the kind of the icon, see
[TabsScreenIconAndroid](#tabsscreeniconandroid).

If no [selectedIcon](#screen-android-selectedicon) is
provided, this icon will also be used as the selected state icon.

**Type:** [`TabsScreenIconAndroid`](#tabsscreeniconandroid)

<ReferenceHeading platforms={[{"platform":"android"}]} source={"src/components/tabs/screen/TabsScreen.android.types.ts#L287"}>
#### android.selectedIcon {#screen-android-selectedicon}
</ReferenceHeading>

```ts
selectedIcon?: TabsScreenIconAndroid;
```

Specifies the icon for tab bar item when it is selected.

Supports the same values as [icon](#screen-android-icon)
property.

**Type:** [`TabsScreenIconAndroid`](#tabsscreeniconandroid)

:::info

To use `selectedIcon`, `icon` must also be provided.

:::

**Default:** The [icon](#screen-android-icon) is used.

**Example:** The drawable is shown tinted while unselected and in its own colors while selected: ```tsx <Tabs.Screen screenKey="favorites" title="Favorites" android={{ icon: { type: 'drawableResource', name: 'ic_star' }, selectedIcon: { type: 'drawableResource', name: 'ic_star', tinting: 'original', }, }}> <FavoritesScreen /> </Tabs.Screen> ```

#### android.standardAppearance {#screen-android-standardappearance}
</ReferenceHeading>

```ts
standardAppearance?: TabsScreenAppearanceAndroid;
```

Specifies the standard tab bar appearance.

Allows to customize the appearance depending on the tab bar item state
([normal](#tabsscreenappearanceandroid-normal),
[selected](#tabsscreenappearanceandroid-selected),
[focused](#tabsscreenappearanceandroid-focused),
[disabled](#tabsscreenappearanceandroid-disabled)). The tab bar uses
the configuration of the currently selected tab screen, except for the
fields that apply to this tab only.

**Type:** [`TabsScreenAppearanceAndroid`](#tabsscreenappearanceandroid)
