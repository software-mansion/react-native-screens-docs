#### android.selectedIcon {#screen-android-selectedicon}
</ReferenceHeading>

```ts
selectedIcon?: TabsScreenIconAndroid;
```

Specifies the icon for tab bar item when it is selected.

Supports the same values as `icon` property for given platform.
`tinting` may differ from the one of `icon`, e.g. a drawable that is
tinted while unselected and shows its own colors while selected.

To use `selectedIcon`, `icon` must also be provided.

**Type:** [`TabsScreenIconAndroid`](#tabsscreeniconandroid)

#### android.standardAppearance {#screen-android-standardappearance}
</ReferenceHeading>

```ts
standardAppearance?: TabsScreenAppearanceAndroid;
```

Specifies the standard tab bar appearance.

Allows to customize the appearance depending on the tab bar item state
(normal, selected, focused, disabled). Configuration for the Bottom
Navigation View is determined by the currently active tab screen.

**Type:** [`TabsScreenAppearanceAndroid`](#tabsscreenappearanceandroid)
