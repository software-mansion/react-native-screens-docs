#### android.icon {#screen-android-icon}
</ReferenceHeading>

```ts
icon?: PlatformIconAndroid;
```

Specifies the icon for the tab bar item.

`imageSource` type doesn't support SVGs on Android. For loading SVGs use `drawableResource`
type, which requires passing a drawable to resources via Android Studio.

**Type:** [`PlatformIconAndroid`](../../../../common-types/index.mdx#platformiconandroid)

#### android.selectedIcon {#screen-android-selectedicon}
</ReferenceHeading>

```ts
selectedIcon?: PlatformIconAndroid;
```

Specifies the icon for tab bar item when it is selected.

Supports the same values as `icon` property for given platform.

To use `selectedIcon`, `icon` must also be provided.

**Type:** [`PlatformIconAndroid`](../../../../common-types/index.mdx#platformiconandroid)

#### android.standardAppearance {#screen-android-standardappearance}
</ReferenceHeading>

```ts
standardAppearance?: TabsScreenAppearanceAndroid;
```

Specifies the standard tab bar appearance.

Allows to customize the appearance depending on the tab bar item state
(normal, selected, focused, disabled). Configuration for the Bottom Navigation View
is determined by the currently active tab screen.

**Type:** [`TabsScreenAppearanceAndroid`](#tabsscreenappearanceandroid)
