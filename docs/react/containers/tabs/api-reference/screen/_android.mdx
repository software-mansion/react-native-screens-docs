#### android.icon? {#screen-android-icon}

> `optional` **icon?**: [`PlatformIconAndroid`](../../../../common-types/index.mdx#platformiconandroid)

Defined in: [components/tabs/screen/TabsScreen.android.types.ts:191](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.android.types.ts#L191)

Specifies the icon for the tab bar item.

`imageSource` type doesn't support SVGs on Android. For loading SVGs use `drawableResource`
type, which requires passing a drawable to resources via Android Studio.

**Platform:** android \>= 21

#### android.selectedIcon? {#screen-android-selectedicon}

> `optional` **selectedIcon?**: [`PlatformIconAndroid`](../../../../common-types/index.mdx#platformiconandroid)

Defined in: [components/tabs/screen/TabsScreen.android.types.ts:202](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.android.types.ts#L202)

Specifies the icon for tab bar item when it is selected.

Supports the same values as `icon` property for given platform.

To use `selectedIcon`, `icon` must also be provided.

**Platform:** android \>= 21

#### android.standardAppearance? {#screen-android-standardappearance}

> `optional` **standardAppearance?**: [`TabsScreenAppearanceAndroid`](#tabsscreenappearanceandroid)

Defined in: [components/tabs/screen/TabsScreen.android.types.ts:181](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.android.types.ts#L181)

Specifies the standard tab bar appearance.

Allows to customize the appearance depending on the tab bar item state
(normal, selected, focused, disabled). Configuration for the Bottom Navigation View
is determined by the currently active tab screen.

**Platform:** android \>= 21
