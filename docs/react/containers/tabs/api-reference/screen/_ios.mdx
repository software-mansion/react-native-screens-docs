#### ios.experimental\_userInterfaceStyle {#screen-ios-experimental_userinterfacestyle}
</ReferenceHeading>

```ts
experimental_userInterfaceStyle?: UserInterfaceStyle;
```

:::warning

This API is experimental. It may change in a breaking way — or be removed entirely — in any release.

:::

Allows to override system appearance for the tab bar.

Consider using `colorScheme` on `Tabs.Host` instead.

**Type:** [`UserInterfaceStyle`](../../../../common-types/index.mdx#userinterfacestyle)

:::note

Does not support dynamic changes to the prop value for the currently visible screen.

:::

**Default:** `'unspecified'`

**See:** [UIUserInterfaceStyle](https://developer.apple.com/documentation/uikit/uiuserinterfacestyle)

#### ios.overrideScrollViewContentInsetAdjustmentBehavior {#screen-ios-overridescrollviewcontentinsetadjustmentbehavior}
</ReferenceHeading>

```ts
overrideScrollViewContentInsetAdjustmentBehavior?: boolean;
```

Specifies if `contentInsetAdjustmentBehavior` of first ScrollView
in first descendant chain from tab screen should be overridden back from `never`
to `automatic`.

By default, `react-native`'s ScrollView has `contentInsetAdjustmentBehavior`
set to `never` instead of UIKit-default (which is `automatic`). This
prevents ScrollViews from respecting navigation bar insets.
When this prop is set to `true`, `automatic` behavior is reverted.

Supported only on Fabric.

**Default:** `true`

#### ios.scrollEdgeAppearance {#screen-ios-scrolledgeappearance}
</ReferenceHeading>

```ts
scrollEdgeAppearance?: TabsScreenAppearanceIOS;
```

Specifies the tab bar appearace when edge of scrollable content aligns
with the edge of the tab bar.

Allows to customize the appearance depending on the tab bar item layout (stacked,
inline, compact inline) and state (normal, selected, focused, disabled).

If this property is `undefined`, UIKit uses `standardAppearance`, modified to
have a transparent background.

**Type:** [`TabsScreenAppearanceIOS`](#tabsscreenappearanceios)

#### ios.systemItem {#screen-ios-systemitem}
</ReferenceHeading>

```ts
systemItem?: TabsScreenSystemItem;
```

System-provided tab bar item with predefined icon and title.

Uses Apple's built-in tab bar items (e.g., bookmarks, contacts, downloads) with
standard iOS styling and localized titles. Custom `icon` or `selectedIcon`
properties will override the system icon, and the system-defined title can be
overridden by providing a custom `title`.

On iOS 26, `systemItem: 'search'` acts as a detached tab bar item, which does not display any title (system or custom).

**Type:** [`TabsScreenSystemItem`](#tabsscreensystemitem)
