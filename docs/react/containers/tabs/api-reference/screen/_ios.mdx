#### ios.overrideScrollViewContentInsetAdjustmentBehavior? {#screen-ios-overridescrollviewcontentinsetadjustmentbehavior}

> `optional` **overrideScrollViewContentInsetAdjustmentBehavior?**: `boolean`

Defined in: [components/tabs/screen/TabsScreen.ios.types.ts:362](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.ios.types.ts#L362)

Specifies if `contentInsetAdjustmentBehavior` of first ScrollView
in first descendant chain from tab screen should be overridden back from `never`
to `automatic`.

##### Remarks

By default, `react-native`'s ScrollView has `contentInsetAdjustmentBehavior`
set to `never` instead of UIKit-default (which is `automatic`). This
prevents ScrollViews from respecting navigation bar insets.
When this prop is set to `true`, `automatic` behavior is reverted.

Supported only on Fabric.

##### Default Value

`true`

##### Platform

ios

##### Since

5.0

#### ios.systemItem? {#screen-ios-systemitem}

> `optional` **systemItem?**: [`TabsScreenSystemItem`](#tabsscreensystemitem)

Defined in: [components/tabs/screen/TabsScreen.ios.types.ts:344](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.ios.types.ts#L344)

System-provided tab bar item with predefined icon and title.

##### Remarks

Uses Apple's built-in tab bar items (e.g., bookmarks, contacts, downloads) with
standard iOS styling and localized titles. Custom `icon` or `selectedIcon`
properties will override the system icon, and the system-defined title can be
overridden by providing a custom `title`.

On iOS 26, `systemItem: 'search'` acts as a detached tab bar item, which does not display any title (system or custom).

##### Platform

ios

##### Since

5.0
