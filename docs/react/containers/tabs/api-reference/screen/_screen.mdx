Specifies content of tab bar item badge.

On iOS, badge is displayed as regular string.

On Android, the value is interpreted in the following order:
- if the string can be parsed to integer, displays the value as a number;
- otherwise if the string is empty, displays "small dot" badge;
- otherwise, displays the value as a text.

**Platform:** android \>= 21, ios \>= 13

#### orientation? {#screen-orientation}

> `optional` **orientation?**: [`TabsScreenOrientation`](#tabsscreenorientation)

Defined in: [components/tabs/screen/TabsScreen.types.ts:181](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.types.ts#L181)

Specifies supported orientations for the tab screen.

Procedure for determining supported orientations:
1. Traversal initiates from the root component and moves to the
   deepest child possible.
2. Components are queried for their supported orientations:
   - if `orientation` is explicitly set (e.g., `'portrait'`,
     `'landscape'`), it is immediately used,
   - if `orientation` is set to `'inherit'`, the parent component
     is queried.

:::note

Exceptions to this procedure:
- some components (like `SplitHost`) may choose not to query
  its child components,
- Stack v4 (legacy) implementation returns some supported orientations,
  overriding orientation from the tab screen **unless** the Stack v4
  screen has no explicit `screenOrientation` prop and
  `featureFlags.experiment.iosOrientationInheritanceFixEnabled` is
  enabled (the default), in which case it returns `'inherit'` and no
  longer overrides the parent (see
  [PR #4408](https://github.com/software-mansion/react-native-screens/pull/4408)).

:::

**Default:** `'inherit'`

**See:** [UIInterfaceOrientationMask](https://developer.apple.com/documentation/uikit/uiinterfaceorientationmask)

**Platform:** ios \>= 13

> `optional` **repeatedTabSelection?**: `object`

the already focused tab bar item).

**Platform:** android \>= 21, ios \>= 13

###### repeatedTabSelection.popToRoot?

> `optional` **popToRoot?**: `boolean`

When a Stack is nested inside the tab screen and repeated
selection is detected, the Stack will pop to its root
screen.

**Default:** `true`

**Platform:** android \>= 21, ios \>= 13

###### repeatedTabSelection.scrollToTop?

> `optional` **scrollToTop?**: `boolean`

When there is a ScrollView in the first descendant chain
from the tab screen and repeated selection is detected, the
ScrollView will be scrolled to top.

**Default:** `true`

**Platform:** android \>= 21, ios \>= 13
