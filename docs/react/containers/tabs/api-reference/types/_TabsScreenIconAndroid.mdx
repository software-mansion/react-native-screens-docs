#### TabsScreenIconAndroid {#tabsscreeniconandroid}
</ReferenceHeading>

```ts
type TabsScreenIconAndroid =
  | TabsScreenIconDrawableResourceAndroid
  | TabsScreenIconImageSourceAndroid;
```

Icon of a tab bar item on Android.

The `type` field selects the kind of the icon. The following kinds are
supported:
- [TabsScreenIconImageSourceAndroid](#tabsscreeniconimagesourceandroid) — an image source.
- [TabsScreenIconDrawableResourceAndroid](#tabsscreenicondrawableresourceandroid) — a drawable resource.

See [TabsScreenIconTintingAndroid](#tabsscreenicontintingandroid) for the meaning of each value.

**Type:** [`TabsScreenIconDrawableResourceAndroid`](#tabsscreenicondrawableresourceandroid) \| [`TabsScreenIconImageSourceAndroid`](#tabsscreeniconimagesourceandroid)
