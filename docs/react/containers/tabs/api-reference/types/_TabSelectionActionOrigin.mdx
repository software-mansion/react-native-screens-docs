#### TabSelectionActionOrigin {#tabselectionactionorigin}
</ReferenceHeading>

```ts
type TabSelectionActionOrigin = "user" | "programmaticJs" | "programmaticNative" | "implicit";
```

Origin (actor) that requested a tab transition.

The following values are supported:
- `'user'` — direct native UI interaction (e.g. tab bar tap, iOS tab
  drag-and-drop).
- `'programmaticJs'` — JS-initiated request delivered via the
  `navStateRequest` prop.
- `'programmaticNative'` — request initiated from the native side by an actor
  integrating directly against the native container.
- `'implicit'` — platform side effect not attributable to an explicit actor
  (e.g. UIKit reshuffling the selection during a horizontal size-class
  transition on iPad). Currently only emitted on iOS.
