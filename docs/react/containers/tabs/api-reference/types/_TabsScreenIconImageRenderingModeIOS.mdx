#### TabsScreenIconImageRenderingModeIOS {#tabsscreeniconimagerenderingmodeios}
</ReferenceHeading>

```ts
type TabsScreenIconImageRenderingModeIOS = "default" | "template" | "original";
```

How the tab bar renders an `imageSource` icon on iOS. The names follow
`UIImage.RenderingMode`.

The following values are supported:
- `'default'` — the system behavior (UIKit's automatic mode), also used
  when `renderingMode` is unset: the tab bar decides how to draw the image.
- `'template'` — the image is used as a template image: its shape is drawn
  in the state-dependent item icon color (`tabBarItemIconColor`,
  `tabBarTintColor`).
- `'original'` — the image keeps its own colors and ignores the item icon
  color.
