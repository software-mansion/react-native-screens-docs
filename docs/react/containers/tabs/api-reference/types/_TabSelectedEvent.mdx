#### TabSelectedEvent {#tabselectedevent}
</ReferenceHeading>

<div className="reference-entry">

```ts
type TabSelectedEvent = {
  actionOrigin: TabSelectionActionOrigin;
  hasTriggeredSpecialEffect: boolean;
  isRepeated: boolean;
  provenance: number;
  selectedScreenKey: string;
};
```

Payload of the event emitted when a tab selection occurs on the native side.

This event is emitted both for user-initiated and programmatic tab changes.
It carries the resulting navigation state along with metadata about the selection context.
