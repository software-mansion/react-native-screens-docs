#### TabsScreenAppearanceIOS {#tabsscreenappearanceios}
</ReferenceHeading>

Appearance of the tab bar while the tab screen is selected.

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.ios.types.ts#L99"}>
##### compactInline {#tabsscreenappearanceios-compactinline}
</ReferenceHeading>

```ts
compactInline?: TabsScreenItemAppearanceIOS;
```

Specifies the appearance of tab bar items when they are in compact inline
layout.

Tab bar items in compact inline layout have the icon next to the title.
Compact inline layout is used in compact-width environments, e.g. in
landscape orientation on the iPhone 16 Pro.

Complete list of size classes for iOS and iPadOS devices is available in
Apple's Human Interface Guidelines.

**Type:** [`TabsScreenItemAppearanceIOS`](#tabsscreenitemappearanceios)

**See:** [HIG: Device size classes](https://developer.apple.com/design/human-interface-guidelines/layout#iOS-iPadOS-device-size-classes)

##### inline {#tabsscreenappearanceios-inline}

```ts
inline?: TabsScreenItemAppearanceIOS;
```

Specifies the appearance of tab bar items when they are in inline layout.

Tab bar items in inline layout have the icon next to the title.

##### stacked {#tabsscreenappearanceios-stacked}
</ReferenceHeading>

```ts
stacked?: TabsScreenItemAppearanceIOS;
```

Specifies the appearance of tab bar items when they are in stacked layout.

Tab bar items in stacked layout have the icon above the title.

##### tabBarBackgroundColor {#tabsscreenappearanceios-tabbarbackgroundcolor}
</ReferenceHeading>

```ts
tabBarBackgroundColor?: ColorValue;
```

Specifies the background color for the entire tab bar when tab screen is
selected.

This property does not affect the tab bar starting from iOS 26.

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.ios.types.ts#L120"}>
##### tabBarBlurEffect {#tabsscreenappearanceios-tabbarblureffect}
</ReferenceHeading>

```ts
tabBarBlurEffect?: TabsScreenBlurEffect;
```

Specifies the blur effect applied to the tab bar when tab screen is
selected.

Works with backgroundColor's alpha `< 1`.

This property does not affect the tab bar starting from iOS 26.

**Type:** [`TabsScreenBlurEffect`](#tabsscreenblureffect)

**Default:** `'systemDefault'`
