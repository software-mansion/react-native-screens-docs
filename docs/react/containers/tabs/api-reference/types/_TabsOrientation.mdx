#### TabsOrientation {#tabsorientation}
</ReferenceHeading>

```ts
type TabsOrientation = InterfaceOrientation | "inherit";
```

Interface orientations a tab screen supports.

Accepts any [InterfaceOrientation](../../../../common-types/index.mdx#interfaceorientation) value, plus:
- `'inherit'` — tab screen supports the same orientations as parent
  component.

**See:** [UIInterfaceOrientationMask](https://developer.apple.com/documentation/uikit/uiinterfaceorientationmask)
