#### TabsColorScheme {#tabscolorscheme}
</ReferenceHeading>

<div className="reference-entry">

```ts
type TabsColorScheme = ColorScheme | "inherit";
```

Color scheme applied to a tabs container and its child containers.

Accepts any [ColorScheme](../../../../common-types/index.mdx#colorscheme) value, plus:
- `'inherit'` — inherit the interface style from the parent.

**Type:** [`ColorScheme`](../../../../common-types/index.mdx#colorscheme) \| `"inherit"`
