Special effects for repeated tab selection (selecting already focused tab
bar item).

[popToRoot](#tabsscreenrepeatedtabselectioneffects-poptoroot) has
priority over
[scrollToTop](#tabsscreenrepeatedtabselectioneffects-scrolltotop).

<ReferenceHeading platforms={[{"platform":"android"},{"platform":"ios"}]} source={"src/components/tabs/screen/TabsScreen.types.ts#L55"}>
##### popToRoot {#tabsscreenrepeatedtabselectioneffects-poptoroot}
</ReferenceHeading>

```ts
popToRoot?: boolean;
```

When Stack is nested inside tab screen and repeated selection is detected,
the Stack will pop to root screen.

**Default:** `true`

<ReferenceHeading platforms={[{"platform":"android"},{"platform":"ios"}]} source={"src/components/tabs/screen/TabsScreen.types.ts#L66"}>
##### scrollToTop {#tabsscreenrepeatedtabselectioneffects-scrolltotop}
</ReferenceHeading>

```ts
scrollToTop?: boolean;
```

When repeated selection is detected, the content scroll view of the tab
screen is scrolled to the top.

The content scroll view can be designated with a [ScrollViewMarker](../../../../components/scroll-view-marker/index.mdx#scroll-view-marker).

**Default:** `true`
