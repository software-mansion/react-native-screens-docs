<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.types.ts#L74"}>
##### popToRoot {#tabsscreenrepeatedtabselectioneffects-poptoroot}
</ReferenceHeading>

```ts
popToRoot?: boolean;
```

When a Stack is nested inside the tab screen and repeated
selection is detected, the Stack will pop to its root
screen.

**Default:** `true`

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.types.ts#L82"}>
##### scrollToTop {#tabsscreenrepeatedtabselectioneffects-scrolltotop}
</ReferenceHeading>

```ts
scrollToTop?: boolean;
```

When there is a ScrollView in the first descendant chain
from the tab screen and repeated selection is detected, the
ScrollView will be scrolled to top.

**Default:** `true`
