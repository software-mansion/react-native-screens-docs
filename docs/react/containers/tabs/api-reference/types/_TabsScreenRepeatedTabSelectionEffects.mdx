#### TabsScreenRepeatedTabSelectionEffects {#tabsscreenrepeatedtabselectioneffects}
</ReferenceHeading>

Special effects applied on repeated tab selection (selecting already focused
tab bar item).

`popToRoot` has priority over `scrollToTop`.

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.types.ts#L64"}>
##### popToRoot {#tabsscreenrepeatedtabselectioneffects-poptoroot}
</ReferenceHeading>

```ts
popToRoot?: boolean;
```

When Stack is nested inside tab screen and repeated selection is detected,
the Stack will pop to root screen.

**Default:** `true`

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.types.ts#L71"}>
##### scrollToTop {#tabsscreenrepeatedtabselectioneffects-scrolltotop}
</ReferenceHeading>

```ts
scrollToTop?: boolean;
```

When there is a ScrollView in first descendant chain from tab screen and
repeated selection is detected, ScrollView will be scrolled to top.

**Default:** `true`
