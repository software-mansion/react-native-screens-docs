#### TabsBlurEffect {#tabsblureffect}
</ReferenceHeading>

```ts
type TabsBlurEffect = BlurEffect | "systemDefault";
```

Blur effect applied to the tab bar.

Accepts any [BlurEffect](../../../../common-types/index.mdx#blureffect) value and `'systemDefault'`, which uses
UIKit's default tab bar blur effect.

**Type:** [`BlurEffect`](../../../../common-types/index.mdx#blureffect) \| `"systemDefault"`
