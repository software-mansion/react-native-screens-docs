<ReferenceHeading source={"src/components/tabs/screen/TabsScreen.ios.types.ts#L172"}>
##### disabled {#tabsscreenitemappearanceios-disabled}
</ReferenceHeading>

```ts
disabled?: TabsScreenItemStateAppearanceIOS;
```

Defines appearance for tab bar items when they are disabled.

The appearance is determined by the configuration of the currently
selected tab.

:::info

Disabling a tab is not supported in v5, so this appearance is not shown.

:::
