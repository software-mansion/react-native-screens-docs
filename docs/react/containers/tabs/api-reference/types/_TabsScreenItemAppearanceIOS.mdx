##### disabled {#tabsscreenitemappearanceios-disabled}
</ReferenceHeading>

```ts
disabled?: TabsScreenItemStateAppearanceIOS;
```

Defines appearance for tab bar items when they are disabled.
The appearance is determined by the configuration of the currently selected
tab.
