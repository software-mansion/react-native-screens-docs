## TabBarItemLabelVisibilityMode {#tabbaritemlabelvisibilitymode}

> **TabBarItemLabelVisibilityMode** = `"auto"` \| `"selected"` \| `"labeled"` \| `"unlabeled"`

Defined in: [components/tabs/screen/TabsScreen.android.types.ts:18](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.android.types.ts#L18)

Determines when tab bar item labels are displayed.

The following values are supported:
- `'auto'` — labels behave as in `'labeled'` mode with 3 items or fewer, or as in `'selected'`
  mode with 4 items or more.
- `'selected'` — the label is only shown on the selected navigation item.
- `'labeled'` — the label is shown on all navigation items.
- `'unlabeled'` — the label is hidden for all navigation items.
