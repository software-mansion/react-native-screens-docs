#### TabsBottomAccessoryComponentFactory {#tabsbottomaccessorycomponentfactory}
</PlatformHeading>

```ts
type TabsBottomAccessoryComponentFactory = (environment: TabsBottomAccessoryEnvironment) => ReactNode;
```

Factory that returns the component rendered as the tab bar's bottom accessory for a given
environment.

**Parameters:**

- `environment`: [`TabsBottomAccessoryEnvironment`](#tabsbottomaccessoryenvironment) — Layout environment the accessory is rendered into.

**Returns:**

`ReactNode`

The element to render as the bottom accessory.
