## TabsScreenItemTitlePositionAdjustmentIOS {#tabsscreenitemtitlepositionadjustmentios}
</PlatformHeading>

Offset of a tab bar item's title, in points.

<PlatformHeading platforms={[{"platform":"ios","from":"13"}]}>
#### horizontal {#tabsscreenitemtitlepositionadjustmentios-horizontal}
</PlatformHeading>

```ts
horizontal?: number;
```

Horizontal offset, in points. Positive values move the title towards the
trailing edge.

<PlatformHeading platforms={[{"platform":"ios","from":"13"}]}>
#### vertical {#tabsscreenitemtitlepositionadjustmentios-vertical}
</PlatformHeading>

```ts
vertical?: number;
```

Vertical offset, in points. Positive values move the title down.
