## TabsScreenSystemItem {#tabsscreensystemitem}

> **TabsScreenSystemItem** = `"bookmarks"` \| `"contacts"` \| `"downloads"` \| `"favorites"` \| `"featured"` \| `"history"` \| `"more"` \| `"mostRecent"` \| `"mostViewed"` \| `"recents"` \| `"search"` \| `"topRated"`

Defined in: [components/tabs/screen/TabsScreen.ios.types.ts:31](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.ios.types.ts#L31)

System-provided tab bar item with a predefined icon and title.

### Remarks

Each value maps to a UIKit `UITabBarItem.SystemItem` of the same name. The following values
are supported: `'bookmarks'`, `'contacts'`, `'downloads'`, `'favorites'`, `'featured'`,
`'history'`, `'more'`, `'mostRecent'`, `'mostViewed'`, `'recents'`, `'search'`, `'topRated'`.
