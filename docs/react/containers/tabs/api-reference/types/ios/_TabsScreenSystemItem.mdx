#### TabsScreenSystemItem {#tabsscreensystemitem}
</ReferenceHeading>

```ts
type TabsScreenSystemItem =
  | "bookmarks"
  | "contacts"
  | "downloads"
  | "favorites"
  | "featured"
  | "history"
  | "more"
  | "mostRecent"
  | "mostViewed"
  | "recents"
  | "search"
  | "topRated";
```

System-provided tab bar item with a predefined icon and title.

Each value maps to a UIKit `UITabBarItem.SystemItem` of the same name. The following values
are supported: `'bookmarks'`, `'contacts'`, `'downloads'`, `'favorites'`, `'featured'`,
`'history'`, `'more'`, `'mostRecent'`, `'mostViewed'`, `'recents'`, `'search'`, `'topRated'`.

**See:** [UITabBarItem.SystemItem](https://developer.apple.com/documentation/uikit/uitabbaritem/systemitem)
