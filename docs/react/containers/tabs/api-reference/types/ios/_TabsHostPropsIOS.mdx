#### bottomAccessory? {#tabshostpropsios-bottomaccessory}

> `optional` **bottomAccessory?**: [`TabsBottomAccessoryComponentFactory`](#tabsbottomaccessorycomponentfactory)

Defined in: [components/tabs/host/TabsHost.ios.types.ts:133](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/host/TabsHost.ios.types.ts#L133)

Specifies component used as bottom accessory.

##### Remarks

This prop is a function that accepts `environment` as a parameter and returns
the component that will be rendered in the bottom accessory — see
[TabsBottomAccessoryEnvironment](#tabsbottomaccessoryenvironment) for the possible environments. If this prop is
`undefined`, the bottom accessory will not be rendered.

##### Warning

In order to allow accessory rendering based on environment, the component is
rendered 2 times for both `'regular'` and `'inline'` environments at the same time.
Environment determines which component is visible at given moment. This might
require implementing a solution to share state between both rendered components
(e.g. usage of context).

##### Platform

ios

##### Supported

iOS \>= 26

##### Since

5.0
