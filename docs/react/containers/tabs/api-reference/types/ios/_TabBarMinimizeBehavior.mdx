## TabBarMinimizeBehavior {#tabbarminimizebehavior}

> **TabBarMinimizeBehavior** = `"automatic"` \| `"never"` \| `"onScrollDown"` \| `"onScrollUp"`

Defined in: [components/tabs/host/TabsHost.ios.types.ts:63](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/host/TabsHost.ios.types.ts#L63)

Minimize behavior of the tab bar as the user scrolls.

The following values are supported:
- `'automatic'` — resolves to the system default minimize behavior.
- `'never'` — the tab bar does not minimize.
- `'onScrollDown'` — the tab bar minimizes when scrolling down and expands when scrolling back up.
- `'onScrollUp'` — the tab bar minimizes when scrolling up and expands when scrolling back down.
