#### tabBarItemIconColor? {#tabsscreenitemstateappearanceios-tabbaritemiconcolor}

> `optional` **tabBarItemIconColor?**: `____ColorValue_Internal`

Defined in: [components/tabs/screen/TabsScreen.ios.types.ts:228](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/screen/TabsScreen.ios.types.ts#L228)

Specifies the icon color for each tab bar item when tab screen
is selected.

##### Remarks

This also impacts the title text color.

Starting from iOS 26, it only applies to selected tab bar item. Other items
adopt a dark or light appearance depending on the theme of the tab bar.

Is overridden by `tabBarItemTitleFontColor` (for title text color).
Overrides `tabBarTintColor`.

##### Platform

ios \>= 13

Specifies the title offset for each tab bar item when tab screen
is selected.

##### horizontal?

> `optional` **horizontal?**: `number`

Horizontal offset, in points. Positive values move the title towards the
trailing edge.

###### Platform

ios \>= 13

##### vertical?

> `optional` **vertical?**: `number`

Vertical offset, in points. Positive values move the title down.

###### Platform

ios \>= 13

##### Remarks

Depending on the iOS version and the device's interface orientation,
this setting may affect the alignment of the text, badge and icon.

##### Platform

ios \>= 13
