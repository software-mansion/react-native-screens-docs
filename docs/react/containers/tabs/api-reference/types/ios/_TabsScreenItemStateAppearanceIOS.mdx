## TabsScreenItemStateAppearanceIOS {#tabsscreenitemstateappearanceios}

Appearance of an iOS tab bar item in a single state.

**Platform:** ios \>= 13

### Properties

#### tabBarItemBadgeBackgroundColor? {#tabsscreenitemstateappearanceios-tabbaritembadgebackgroundcolor}

```ts
tabBarItemBadgeBackgroundColor?: ____ColorValue_Internal;
```

Specifies the background color of badges for each tab bar item
when tab screen is selected.

**Platform:** ios \>= 13

#### tabBarItemIconColor? {#tabsscreenitemstateappearanceios-tabbaritemiconcolor}

```ts
tabBarItemIconColor?: ____ColorValue_Internal;
```

Specifies the icon color for each tab bar item when tab screen
is selected.

This also impacts the title text color.

Starting from iOS 26, it only applies to selected tab bar item. Other items
adopt a dark or light appearance depending on the theme of the tab bar.

Is overridden by `tabBarItemTitleFontColor` (for title text color).
Overrides `tabBarTintColor`.

**Platform:** ios \>= 13

#### tabBarItemTitleFontColor? {#tabsscreenitemstateappearanceios-tabbaritemtitlefontcolor}

```ts
tabBarItemTitleFontColor?: ____ColorValue_Internal;
```

Specifies the font color used for the title of each tab bar item
when tab screen is selected.

Overrides the color defined in `tabBarTintColor` and `tabBarItemIconColor`.

**Platform:** ios \>= 13

#### tabBarItemTitleFontFamily? {#tabsscreenitemstateappearanceios-tabbaritemtitlefontfamily}

```ts
tabBarItemTitleFontFamily?: string;
```

Specifies the font family used for the title of each tab bar item
when tab screen is selected.

**Platform:** ios \>= 13

#### tabBarItemTitleFontSize? {#tabsscreenitemstateappearanceios-tabbaritemtitlefontsize}

```ts
tabBarItemTitleFontSize?: number;
```

Specifies the font size used for the title of each tab bar item
when tab screen is selected.

**Platform:** ios \>= 13

#### tabBarItemTitleFontStyle? {#tabsscreenitemstateappearanceios-tabbaritemtitlefontstyle}

```ts
tabBarItemTitleFontStyle?: "normal" | "italic";
```

Specifies the font style used for the title of each tab bar item
when tab screen is selected.

**Platform:** ios \>= 13

#### tabBarItemTitleFontWeight? {#tabsscreenitemstateappearanceios-tabbaritemtitlefontweight}

```ts
tabBarItemTitleFontWeight?: ____FontWeight_Internal;
```

Specifies the font weight used for the title of each tab bar item
when tab screen is selected.

**Platform:** ios \>= 13

#### tabBarItemTitlePositionAdjustment? {#tabsscreenitemstateappearanceios-tabbaritemtitlepositionadjustment}

```ts
tabBarItemTitlePositionAdjustment?: TabsScreenItemTitlePositionAdjustmentIOS;
```

Specifies the title offset for each tab bar item when tab screen
is selected.

Depending on the iOS version and the device's interface orientation,
this setting may affect the alignment of the text, badge and icon.

**Type:** [`TabsScreenItemTitlePositionAdjustmentIOS`](#tabsscreenitemtitlepositionadjustmentios)

**Platform:** ios \>= 13
