<ReferenceHeading platforms={[{"platform":"ios","from":"13"}]} source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.ios.types.ts#L101"}>
##### compactInline {#tabsscreenappearanceios-compactinline}
</ReferenceHeading>

```ts
compactInline?: TabsScreenItemAppearanceIOS;
```

Specifies the appearance of tab bar items when they are in compact inline layout.

Tab bar items in compact inline layout have the icon next to the title.
Compact inline layout is used in compact-width environments, e.g. in landscape orientation on the iPhone 16 Pro.

**Type:** [`TabsScreenItemAppearanceIOS`](#tabsscreenitemappearanceios)

**See:** [HIG: Device size classes](https://developer.apple.com/design/human-interface-guidelines/layout#iOS-iPadOS-device-size-classes)
