#### TabsScreenBlurEffect {#tabsscreenblureffect}
</PlatformHeading>

```ts
type TabsScreenBlurEffect = BlurEffect | "systemDefault";
```

Blur effect applied to the tab bar background.

Accepts any [BlurEffect](../../../../../common-types/index.mdx#blureffect) value, plus:
- `'systemDefault'` — use UIKit's default tab bar blur effect.

**Type:** [`BlurEffect`](../../../../../common-types/index.mdx#blureffect) \| `"systemDefault"`
