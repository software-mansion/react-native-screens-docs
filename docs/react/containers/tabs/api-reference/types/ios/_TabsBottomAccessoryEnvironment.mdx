#### TabsBottomAccessoryEnvironment {#tabsbottomaccessoryenvironment}
</PlatformHeading>

```ts
type TabsBottomAccessoryEnvironment = "regular" | "inline";
```

Layout environment in which a tab bar bottom accessory is rendered.

The following values are supported:
- `'regular'` — the accessory is laid out above the bottom tab bar.
- `'inline'` — the accessory is laid out inline with the collapsed bottom tab bar.
