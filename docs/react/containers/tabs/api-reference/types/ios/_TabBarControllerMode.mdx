## TabBarControllerMode {#tabbarcontrollermode}

> **TabBarControllerMode** = `"automatic"` \| `"tabBar"` \| `"tabSidebar"`

Defined in: [components/tabs/host/TabsHost.ios.types.ts:81](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/host/TabsHost.ios.types.ts#L81)

Display mode of the tab bar.

The following values are supported:
- `'automatic'` — the system sets the display mode based on the tab's content.
- `'tabBar'` — the system displays the content only as a tab bar.
- `'tabSidebar'` — the tab bar is displayed as a sidebar.
