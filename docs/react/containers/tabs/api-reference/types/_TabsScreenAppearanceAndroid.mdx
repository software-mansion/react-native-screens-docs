#### TabsScreenAppearanceAndroid {#tabsscreenappearanceandroid}
</ReferenceHeading>

Appearance of the tab bar and its items while the tab screen is active.

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.android.types.ts#L95"}>
##### disabled {#tabsscreenappearanceandroid-disabled}
</ReferenceHeading>

```ts
disabled?: TabsScreenItemStateAppearanceAndroid;
```

Defines the colors for tab bar items when they are disabled.
The color scheme is determined by the configuration of the currently
selected tab.

**Type:** [`TabsScreenItemStateAppearanceAndroid`](#tabsscreenitemstateappearanceandroid)

:::note

This is an implementation detail and may change. Maps to Android
`state_enabled=false`.

:::

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/tabs/screen/TabsScreen.android.types.ts#L85"}>

focused?: TabsScreenItemStateAppearanceAndroid;

**Type:** [`TabsScreenItemStateAppearanceAndroid`](#tabsscreenitemstateappearanceandroid)
