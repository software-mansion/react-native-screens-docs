#### TabsScreenIconIOS {#tabsscreeniconios}
</ReferenceHeading>

```ts
type TabsScreenIconIOS = TabsScreenIconSfSymbolIOS | TabsScreenIconImageSourceIOS;
```

Icon of a tab bar item on iOS.

The `type` field selects the kind of the icon. The following kinds are
supported:
- [TabsScreenIconImageSourceIOS](#tabsscreeniconimagesourceios) — an image source.
- [TabsScreenIconSfSymbolIOS](#tabsscreeniconsfsymbolios) — an SF Symbol.

See [TabsScreenIconImageRenderingModeIOS](#tabsscreeniconimagerenderingmodeios) and
[TabsScreenIconSymbolRenderingModeIOS](#tabsscreeniconsymbolrenderingmodeios) for the meaning of each
rendering mode.

**Type:** [`TabsScreenIconSfSymbolIOS`](#tabsscreeniconsfsymbolios) \| [`TabsScreenIconImageSourceIOS`](#tabsscreeniconimagesourceios)
