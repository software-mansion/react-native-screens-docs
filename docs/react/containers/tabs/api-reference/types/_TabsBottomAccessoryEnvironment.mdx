#### TabsBottomAccessoryEnvironment {#tabsbottomaccessoryenvironment}
</ReferenceHeading>

```ts
type TabsBottomAccessoryEnvironment = "regular" | "inline";
```

Environment the bottom accessory is laid out in.

The following values are supported:
- `'regular'` — the accessory is laid out above the bottom tab bar,
- `'inline'` — the accessory is laid out inline with the collapsed bottom
  tab bar.

**See:** [UITabAccessory.Environment](https://developer.apple.com/documentation/uikit/uitabaccessory/environment)
