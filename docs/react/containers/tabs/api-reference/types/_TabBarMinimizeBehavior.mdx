#### TabBarMinimizeBehavior {#tabbarminimizebehavior}
</ReferenceHeading>

```ts
type TabBarMinimizeBehavior = "automatic" | "never" | "onScrollDown" | "onScrollUp";
```

Minimize behavior of the tab bar.

The following values are currently supported:
- `'automatic'` — resolves to the system default minimize behavior
- `'never'` — the tab bar does not minimize
- `'onScrollDown'` — the tab bar minimizes when scrolling down and expands
  when scrolling back up
- `'onScrollUp'` — the tab bar minimizes when scrolling up and expands when
  scrolling back down

**See:** [UITabBarController.MinimizeBehavior](https://developer.apple.com/documentation/uikit/uitabbarcontroller/minimizebehavior)
