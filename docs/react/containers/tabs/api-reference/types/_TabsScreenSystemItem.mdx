#### TabsScreenSystemItem {#tabsscreensystemitem}
</ReferenceHeading>

```ts
type TabsScreenSystemItem =
  | "bookmarks"
  | "contacts"
  | "downloads"
  | "favorites"
  | "featured"
  | "history"
  | "more"
  | "mostRecent"
  | "mostViewed"
  | "recents"
  | "search"
  | "topRated";
```

System-provided tab bar item.

The following values are supported:
- `'bookmarks'`
- `'contacts'`
- `'downloads'`
- `'favorites'`
- `'featured'`
- `'history'`
- `'more'`
- `'mostRecent'`
- `'mostViewed'`
- `'recents'`
- `'search'`
- `'topRated'`

**See:** [UITabBarItem.SystemItem](https://developer.apple.com/documentation/uikit/uitabbaritem/systemitem)
