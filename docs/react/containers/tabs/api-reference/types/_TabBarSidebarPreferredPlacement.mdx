#### TabBarSidebarPreferredPlacement {#tabbarsidebarpreferredplacement}
</ReferenceHeading>

```ts
type TabBarSidebarPreferredPlacement = "automatic" | "sidebar" | "tabBar";
```

Whether the sidebar or the tab bar is preferred when only one of them can be
displayed.

The following values are currently supported:
- `'automatic'` — the system resolves to the platform default
- `'sidebar'` — the sidebar is displayed when it is available
- `'tabBar'` — the tab bar is displayed

**See:** [UITabBarController.Sidebar.Placement](https://developer.apple.com/documentation/uikit/uitabbarcontroller/sidebar-swift.class/placement)
