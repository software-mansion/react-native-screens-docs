#### TabBarSidebarPreferredPlacement {#tabbarsidebarpreferredplacement}
</ReferenceHeading>

```ts
type TabBarSidebarPreferredPlacement = "automatic" | "sidebar" | "tabBar";
```

Preference between the sidebar and the tab bar when only one of them can be
displayed.

The following values are currently supported:
- `'automatic'` — the system resolves to the platform default (the tab bar on
  iOS)
- `'sidebar'` — the sidebar is displayed when it is available
- `'tabBar'` — the tab bar is displayed
