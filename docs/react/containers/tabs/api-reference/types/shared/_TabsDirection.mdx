#### TabsDirection {#tabsdirection}
</PlatformHeading>

```ts
type TabsDirection = Direction | "inherit";
```

Layout direction applied to a tabs container and its child containers.

Accepts any [Direction](../../../../../common-types/index.mdx#direction) value, plus:
- `'inherit'` — inherit the layout direction from the parent.

**Type:** [`Direction`](../../../../../common-types/index.mdx#direction) \| `"inherit"`
