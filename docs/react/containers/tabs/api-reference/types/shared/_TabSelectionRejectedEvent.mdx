## TabSelectionRejectedEvent {#tabselectionrejectedevent}

> **TabSelectionRejectedEvent** = `object`

Defined in: [components/tabs/host/TabsHost.types.ts:142](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/host/TabsHost.types.ts#L142)

Payload of the event emitted when the native side rejects a tab selection request.

Contains the currently active navigation state (`selectedScreenKey`, `provenance`)
alongside the rejected request details, so that the JS side can reconcile its state.

**See:**

- [TabSelectionRejectionReason](#tabselectionrejectionreason) for possible rejection reasons.
 - [TabsHostPropsBase.rejectStaleNavStateUpdates](#host-rejectstalenavstateupdates)

**Platform:** android \>= 21, ios \>= 13
