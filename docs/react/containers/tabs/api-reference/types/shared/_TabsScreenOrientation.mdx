#### TabsScreenOrientation {#tabsscreenorientation}
</ReferenceHeading>

```ts
type TabsScreenOrientation = InterfaceOrientation | "inherit";
```

Set of interface orientations a tab screen supports.

Accepts any [InterfaceOrientation](../../../../../common-types/index.mdx#interfaceorientation) value, plus:
- `'inherit'` — the tab screen supports the same orientations as its parent component.

**Type:** [`InterfaceOrientation`](../../../../../common-types/index.mdx#interfaceorientation) \| `"inherit"`
