## TabSelectionPreventedEvent {#tabselectionpreventedevent}
</PlatformHeading>

```ts
type TabSelectionPreventedEvent = {
  preventedScreenKey: string;
  provenance: number;
  selectedScreenKey: string;
};
```

Payload of the event emitted when the native side prevents a tab selection
because the target screen has `preventNativeSelection` enabled.

<PlatformHeading platforms={[{"platform":"android","from":"21"},{"platform":"ios","from":"13"}]}>
#### preventedScreenKey {#tabselectionpreventedevent-preventedscreenkey}
</PlatformHeading>

```ts
preventedScreenKey: string;
```

Screen key of the tab whose selection was prevented.

<PlatformHeading platforms={[{"platform":"android","from":"21"},{"platform":"ios","from":"13"}]}>
#### provenance {#tabselectionpreventedevent-provenance}
</PlatformHeading>

```ts
provenance: number;
```

Provenance of the currently active navigation state.

<PlatformHeading platforms={[{"platform":"android","from":"21"},{"platform":"ios","from":"13"}]}>
#### selectedScreenKey {#tabselectionpreventedevent-selectedscreenkey}
</PlatformHeading>

```ts
selectedScreenKey: string;
```

Screen key of the currently selected (active) tab.
