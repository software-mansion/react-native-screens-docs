## TabSelectedEvent {#tabselectedevent}

```ts
type TabSelectedEvent = {
  actionOrigin: TabSelectionActionOrigin;
  hasTriggeredSpecialEffect: boolean;
  isRepeated: boolean;
  provenance: number;
  selectedScreenKey: string;
};
```

Payload of the event emitted when a tab selection occurs on the native side.

This event is emitted both for user-initiated and programmatic tab changes.
It carries the resulting navigation state along with metadata about the selection context.

**Platform:** android \>= 21, ios \>= 13

### Properties

#### actionOrigin {#tabselectedevent-actionorigin}

```ts
actionOrigin: TabSelectionActionOrigin;
```

Origin (actor) that requested this tab transition.

**Type:** [`TabSelectionActionOrigin`](#tabselectionactionorigin)

**Platform:** android \>= 21, ios \>= 13

#### hasTriggeredSpecialEffect {#tabselectedevent-hastriggeredspecialeffect}

```ts
hasTriggeredSpecialEffect: boolean;
```

Whether the selection triggered a special effect (e.g. scroll-to-top on repeated selection).

**Platform:** android \>= 21, ios \>= 13

#### isRepeated {#tabselectedevent-isrepeated}

```ts
isRepeated: boolean;
```

Whether the same tab that was already selected has been selected again.

**Platform:** android \>= 21, ios \>= 13

#### provenance {#tabselectedevent-provenance}

```ts
provenance: number;
```

Provenance of the navigation state after the selection.

**Platform:** android \>= 21, ios \>= 13

#### selectedScreenKey {#tabselectedevent-selectedscreenkey}

```ts
selectedScreenKey: string;
```

Screen key of the newly selected tab.

**Platform:** android \>= 21, ios \>= 13
