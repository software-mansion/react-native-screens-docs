## TabSelectedEvent {#tabselectedevent}

> **TabSelectedEvent** = `object`

Defined in: [components/tabs/host/TabsHost.types.ts:75](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/host/TabsHost.types.ts#L75)

Payload of the event emitted when a tab selection occurs on the native side.

### Remarks

This event is emitted both for user-initiated and programmatic tab changes.
It carries the resulting navigation state along with metadata about the selection context.

### Platform

android \>= 21, ios \>= 13

#### actionOrigin {#tabselectedevent-actionorigin}

> **actionOrigin**: `"user"` \| `"programmatic-js"` \| `"programmatic-native"` \| `"implicit"`

Defined in: [components/tabs/host/TabsHost.types.ts:115](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/tabs/host/TabsHost.types.ts#L115)

Origin (actor) that requested this tab transition.

##### Remarks

The following values are supported:
- `'user'` — direct native UI interaction (e.g. tab bar tap, iOS tab drag-and-drop).
- `'programmatic-js'` — JS-initiated request delivered via the `navStateRequest` prop.
- `'programmatic-native'` — request initiated from the native side by an actor
  integrating directly against the native container.
- `'implicit'` — platform side effect not attributable to an explicit actor
  (e.g. UIKit reshuffling the selection during a horizontal size-class transition on iPad).
  Currently only emitted on iOS.

android \>= 21, ios \>= 13
