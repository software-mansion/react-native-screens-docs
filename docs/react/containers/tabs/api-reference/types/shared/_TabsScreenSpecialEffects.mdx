## TabsScreenSpecialEffects {#tabsscreenspecialeffects}

Special effects (microinteractions) of a tab screen.

**Platform:** android \>= 21, ios \>= 13

### Properties

#### repeatedTabSelection? {#tabsscreenspecialeffects-repeatedtabselection}

```ts
repeatedTabSelection?: TabsScreenRepeatedTabSelectionEffects;
```

Special effects triggered by repeated tab selection (selecting
the already focused tab bar item).

`popToRoot` has priority over `scrollToTop`.

**Type:** [`TabsScreenRepeatedTabSelectionEffects`](#tabsscreenrepeatedtabselectioneffects)

**Platform:** android \>= 21, ios \>= 13
