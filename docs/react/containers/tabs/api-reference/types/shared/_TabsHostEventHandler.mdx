## TabsHostEventHandler {#tabshosteventhandler}

```ts
type TabsHostEventHandler<T> = (event: NativeSyntheticEvent<T>) => void;
```

Handler for a tab host native synthetic event.

**Platform:** android \>= 21, ios \>= 13

**Type Parameters:**

- `T` — Payload the native event carries.

**Parameters:**

- `event`: `NativeSyntheticEvent`\<`T`\> — The native synthetic event.

**Returns:** `void`
