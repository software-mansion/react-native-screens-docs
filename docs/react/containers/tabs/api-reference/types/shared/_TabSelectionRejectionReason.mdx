## TabSelectionRejectionReason {#tabselectionrejectionreason}

```ts
type TabSelectionRejectionReason = "stale" | "repeated";
```

Reason why a tab selection request was rejected by the native side.

The following values are supported:
- `'stale'` — the update was based on a stale navigation state, meaning a newer state has
  already been applied. Only reported when
  [TabsHostPropsBase.rejectStaleNavStateUpdates](#host-rejectstalenavstateupdates) is enabled.
- `'repeated'` — the requested tab is already selected.

**Platform:** android \>= 21, ios \>= 13
