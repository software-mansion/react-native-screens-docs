#### ios.bottomAccessory {#host-ios-bottomaccessory}
</ReferenceHeading>

```ts
bottomAccessory?: TabsBottomAccessoryComponentFactory;
```

Specifies component used as bottom accessory.

This prop is a function that accepts `environment` as a parameter and returns
the component that will be rendered in the bottom accessory — see
[TabsBottomAccessoryEnvironment](#tabsbottomaccessoryenvironment) for the possible environments. If this prop is
`undefined`, the bottom accessory will not be rendered.

**Type:** [`TabsBottomAccessoryComponentFactory`](#tabsbottomaccessorycomponentfactory)

:::warning

In order to allow accessory rendering based on environment, the component is
rendered 2 times for both `'regular'` and `'inline'` environments at the same time.
Environment determines which component is visible at given moment. This might
require implementing a solution to share state between both rendered components
(e.g. usage of context).

:::

#### ios.onMoreTabSelected {#host-ios-onmoretabselected}
</ReferenceHeading>

```ts
onMoreTabSelected?: TabsHostEventHandler<MoreTabSelectedEvent>;
```

A callback that gets invoked when the user taps the "More" tab bar item.

This event fires when the user taps the system-generated "More" tab bar item.
It does NOT fire when a tab is selected from within the More list — that triggers
the normal `onTabSelected` event instead.

**Type:** [`TabsHostEventHandler`](#tabshosteventhandler)\<[`MoreTabSelectedEvent`](#moretabselectedevent)\>

```ts
tabBarTintColor?: ____ColorValue_Internal;
```

Specifies the color used for selected tab's text and icon color.

Starting from iOS 26, it also impacts glow of Liquid Glass tab
selection view.

`tabBarItemTitleFontColor` and `tabBarItemIconColor` defined on
`Tabs.Screen` override this color.
