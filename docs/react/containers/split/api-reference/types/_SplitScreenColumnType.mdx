#### SplitScreenColumnType {#splitscreencolumntype}
</ReferenceHeading>

```ts
type SplitScreenColumnType = "column" | "inspector";
```

Kind of a Split column.

The following values are supported:
- `'column'` — a column declared with [Split.Column](#column).
- `'inspector'` — the inspector column declared with
  [Split.Inspector](#inspector).
