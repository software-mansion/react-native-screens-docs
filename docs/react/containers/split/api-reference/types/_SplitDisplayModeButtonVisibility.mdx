#### SplitDisplayModeButtonVisibility {#splitdisplaymodebuttonvisibility}
</ReferenceHeading>

```ts
type SplitDisplayModeButtonVisibility = "always" | "automatic" | "never";
```

Visibility of the button for changing the Split display mode.

The following values are currently supported:
- `'automatic'` — the visibility of the display mode button is set by
  system
- `'always'` — the display mode button is always visible
- `'never'` — the display mode button is always hidden

**See:** [UISplitViewController.DisplayModeButtonVisibility](https://developer.apple.com/documentation/uikit/uisplitviewcontroller/displaymodebuttonvisibility-swift.enum)
