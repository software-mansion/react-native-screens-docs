## DisplayModeWillChangeEvent {#displaymodewillchangeevent}

```ts
type DisplayModeWillChangeEvent = {
  currentDisplayMode: string;
  nextDisplayMode: string;
};
```

Payload of the event emitted when the Split display mode is about to change.

**Platform:** ios \>= 13

### Properties

#### currentDisplayMode {#displaymodewillchangeevent-currentdisplaymode}

```ts
currentDisplayMode: string;
```

The display mode in effect when the change was requested.

**Platform:** ios \>= 13

#### nextDisplayMode {#displaymodewillchangeevent-nextdisplaymode}

```ts
nextDisplayMode: string;
```

The display mode the split view is about to adopt.

**Platform:** ios \>= 13
