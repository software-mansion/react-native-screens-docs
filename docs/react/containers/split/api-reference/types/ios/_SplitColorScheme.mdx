## SplitColorScheme {#splitcolorscheme}

```ts
type SplitColorScheme = ColorScheme | "inherit";
```

Color scheme applied to a Split host and its child containers.

Accepts any [ColorScheme](../../../../../common-types/index.mdx#colorscheme) value, plus:
- `'inherit'` — the interface style from parent.

**Type:** [`ColorScheme`](../../../../../common-types/index.mdx#colorscheme) \| `"inherit"`

**Platform:** ios \>= 13
