#### SplitPrimaryBackgroundStyle {#splitprimarybackgroundstyle}
</ReferenceHeading>

```ts
type SplitPrimaryBackgroundStyle = "default" | "none" | "sidebar";
```

Background style of the primary view controller in a Split.

The following values are supported:
- `'default'` — chosen by the OS, the appropriate background style is based on the device preferences.
- `'none'` — a style that has no visual effect on the background appearance of the primary view controller.
- `'sidebar'` — a style that applies a blurred effect to the background of the primary view controller.

**See:** [UISplitViewController.BackgroundStyle](https://developer.apple.com/documentation/uikit/uisplitviewcontroller/backgroundstyle)
