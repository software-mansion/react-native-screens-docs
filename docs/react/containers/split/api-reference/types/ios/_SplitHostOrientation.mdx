## SplitHostOrientation {#splithostorientation}
</PlatformHeading>

```ts
type SplitHostOrientation = InterfaceOrientation | "inherit";
```

Set of interface orientations a Split host supports.

Accepts any [InterfaceOrientation](../../../../../common-types/index.mdx#interfaceorientation) value, plus:
- `'inherit'` — the split host supports the same orientations as its parent
  component.

**Type:** [`InterfaceOrientation`](../../../../../common-types/index.mdx#interfaceorientation) \| `"inherit"`

**See:** [UIInterfaceOrientationMask](https://developer.apple.com/documentation/uikit/uiinterfaceorientationmask)
