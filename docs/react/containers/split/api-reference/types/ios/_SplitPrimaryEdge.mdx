## SplitPrimaryEdge {#splitprimaryedge}
</PlatformHeading>

```ts
type SplitPrimaryEdge = "leading" | "trailing";
```

Edge of the interface on which the primary sidebar is placed.

The following values are supported:
- `'leading'` — primary sidebar is placed on the leading edge of the interface.
- `'trailing'` — primary sidebar is placed on the trailing edge of the interface.

**See:** [UISplitViewController.PrimaryEdge](https://developer.apple.com/documentation/uikit/uisplitviewcontroller/primaryedge-swift.enum)
