## SplitHostEventHandler {#splithosteventhandler}

```ts
type SplitHostEventHandler<T> = (e: NativeSyntheticEvent<T>) => void;
```

Handler for a split host native synthetic event.

**Platform:** ios \>= 13

**Type Parameters:**

- `T` — Payload the native event carries.

**Parameters:**

- `e`: `NativeSyntheticEvent`\<`T`\> — The native synthetic event.

**Returns:** `void`
