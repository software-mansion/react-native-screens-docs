#### SplitOrientation {#splitorientation}
</ReferenceHeading>

```ts
type SplitOrientation = InterfaceOrientation | "inherit";
```

Supported orientations of a Split.

Accepts any [InterfaceOrientation](../../../../common-types/index.mdx#interfaceorientation) value, plus:
- `'inherit'` — Split supports the same orientations as parent component.

**See:** [UIInterfaceOrientationMask](https://developer.apple.com/documentation/uikit/uiinterfaceorientationmask)
