#### SplitPrimaryEdge {#splitprimaryedge}
</ReferenceHeading>

```ts
type SplitPrimaryEdge = "leading" | "trailing";
```

Side on which the primary sidebar of a Split is placed.

The following values are currently supported:
- `'leading'` — primary sidebar is placed on the leading edge of the
  interface
- `'trailing'` — primary sidebar is placed on the trailing edge of the
  interface

**See:** [UISplitViewController.PrimaryEdge](https://developer.apple.com/documentation/uikit/uisplitviewcontroller/primaryedge-swift.enum)
