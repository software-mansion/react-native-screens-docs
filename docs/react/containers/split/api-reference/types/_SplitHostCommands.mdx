##### hide {#splithostcommands-hide}
</ReferenceHeading>

```ts
hide: (column: Exclude<SplitNavigableColumn, "secondary">) => void;
```

Hides a sidebar column using UIKit's native transition to the closest
supported display mode. UIKit does not support hiding the secondary column.

**See:** [UISplitViewController.hide(\_:)](https://developer.apple.com/documentation/uikit/uisplitviewcontroller/hide(_:))

**Parameters:**

- `column`: `Exclude`\<[`SplitNavigableColumn`](#splitnavigablecolumn), `"secondary"`\> — The sidebar column to hide.

**Returns:** `void`
