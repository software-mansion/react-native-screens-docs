#### orientation {#host-orientation}
</PlatformHeading>

```ts
orientation?: SplitHostOrientation;
```

Specifies supported orientations for the split host.

Procedure for determining supported orientations:
1. Traversal initiates from the root component and moves to the
   deepest child possible.
2. Components are queried for their supported orientations:
   - if `orientation` is explicitly set (e.g., `'portrait'`,
     `'landscape'`), it is immediately used,
   - if `orientation` is set to `'inherit'`, the parent component
     is queried.

**Type:** [`SplitHostOrientation`](#splithostorientation)

**Default:** `'inherit'`

#### topColumnForCollapsing {#host-topcolumnforcollapsing}
</PlatformHeading>

```ts
topColumnForCollapsing?: SplitNavigableColumn;
```

Specifies which column should be shown when the split view collapses to a single column.

When the split view transitions from an expanded to a collapsed layout (e.g. rotating an iPad to portrait),
this prop determines which column becomes the top (visible) column.

When not set, the system default behavior is used.
