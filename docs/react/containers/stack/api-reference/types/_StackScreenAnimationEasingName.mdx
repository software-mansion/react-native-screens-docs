#### StackScreenAnimationEasingName {#stackscreenanimationeasingname}
</ReferenceHeading>

```ts
type StackScreenAnimationEasingName =
  | "linear"
  | "easeIn"
  | "easeOut"
  | "easeInOut"
  | "standard"
  | "standardAccelerate"
  | "standardDecelerate"
  | "emphasized"
  | "emphasizedAccelerate"
  | "emphasizedDecelerate";
```

Name of an easing curve.

The following values are supported:
- `'linear'` — constant speed.
- `'easeIn'`, `'easeOut'`, `'easeInOut'` — the CSS `ease-in`, `ease-out`
  and `ease-in-out` curves.
- `'standard'`, `'standardAccelerate'`, `'standardDecelerate'`,
  `'emphasized'`, `'emphasizedAccelerate'`, `'emphasizedDecelerate'` — the
  Material 3 easing tokens of the same names.

**See:**

- [CSS easing functions](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/easing-function)
 - [Material 3 easing tokens](https://m3.material.io/styles/motion/easing-and-duration/tokens-specs)
