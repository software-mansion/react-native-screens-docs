## StackHeaderToolbarMenuBaseAndroid {#stackheadertoolbarmenubaseandroid}

Base fields describing one level of the toolbar menu.

**Platform:** android \>= 21

### Properties

#### children? {#stackheadertoolbarmenubaseandroid-children}

```ts
children?: StackHeaderToolbarMenuElementAndroid[];
```

Menu elements displayed in the toolbar menu.

**Type:** [`StackHeaderToolbarMenuElementAndroid[]`](#stackheadertoolbarmenuelementandroid)

**Platform:** android \>= 21

#### groups? {#stackheadertoolbarmenubaseandroid-groups}

```ts
groups?: StackHeaderToolbarMenuGroupAndroid[];
```

Group definitions for items in this menu level.

Groups enable selection behavior (single or multi-toggle) for
items that share the same `groupId`. A group is scoped to the
menu level it is defined in — groups cannot span submenus.

**Type:** [`StackHeaderToolbarMenuGroupAndroid[]`](#stackheadertoolbarmenugroupandroid)

**Platform:** android \>= 21
