## StackHeaderBackgroundSubviewAndroid {#stackheaderbackgroundsubviewandroid}

Custom React subview stretched across the header as its background.

**Platform:** android \>= 21

### Properties

#### collapseMode? {#stackheaderbackgroundsubviewandroid-collapsemode}

```ts
collapseMode?: StackHeaderSubviewCollapseModeAndroid;
```

Controls how the background subview behaves when the app bar
collapses.

`pin` is not currently supported because the background subview is
stretched to match the entire `AppBarLayout`, which causes pinned content
to move immediately rather than staying fixed. Support for `pin` collapse
mode might be added in the future.

**Type:** [`StackHeaderSubviewCollapseModeAndroid`](#stackheadersubviewcollapsemodeandroid)

**Default:** `'off'`

**Platform:** android \>= 21

#### render {#stackheaderbackgroundsubviewandroid-render}

```ts
render: StackHeaderElementFactory;
```

Render callback for the React element used as the header
background.

The subview is stretched to match the header (`AppBarLayout`) dimensions,
so parent-relative sizing (e.g. `flex: 1`) works correctly.

**Type:** [`StackHeaderElementFactory`](#stackheaderelementfactory)

**Platform:** android \>= 21
