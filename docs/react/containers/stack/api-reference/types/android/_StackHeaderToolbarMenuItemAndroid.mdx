## StackHeaderToolbarMenuItemAndroid {#stackheadertoolbarmenuitemandroid}
</PlatformHeading>

A single actionable item of the toolbar menu.

**Extends:** [`StackHeaderToolbarMenuItemBaseAndroid`](#stackheadertoolbarmenuitembaseandroid)

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
#### groupId {#stackheadertoolbarmenuitemandroid-groupid}
</PlatformHeading>

```ts
groupId?: string;
```

Assigns this item to a group.

Groups enable selection behavior (single-selection / radio, or
multi-toggle). A group is scoped to the menu level it is defined
in — groups cannot span submenus.

Required when `itemType` is `'toggle'`. Cannot be set when
`itemType` is `'action'`.

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
#### initialToggleState {#stackheadertoolbarmenuitemandroid-initialtogglestate}
</PlatformHeading>

```ts
initialToggleState?: boolean;
```

Initial checked state for toggle items.

Only meaningful when effective `itemType` is `'toggle'`.

The initial state does not trigger `onSelectionChange` on
the group at mount time.

**Default:** `false`

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
#### itemType {#stackheadertoolbarmenuitemandroid-itemtype}
</PlatformHeading>

```ts
itemType?: StackHeaderToolbarMenuItemTypeAndroid;
```

Controls how the item behaves when clicked.

If `'toggle'` menu item is shown in the toolbar by setting `showAsAction`
prop to value other than `'never'`, there is no visual indication of the
item toggle state.

**Type:** [`StackHeaderToolbarMenuItemTypeAndroid`](#stackheadertoolbarmenuitemtypeandroid)

**Default:** `'automatic'`

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
#### onPress {#stackheadertoolbarmenuitemandroid-onpress}
</PlatformHeading>

```ts
onPress?: StackHeaderPressHandler;
```

Callback invoked when the menu item is pressed.

Not called for items that behave as toggles (items with a
`groupId` or `itemType: 'toggle'`). For those items, use
`onSelectionChange` on the group instead.

**Type:** [`StackHeaderPressHandler`](#stackheaderpresshandler)
