## StackHeaderToolbarMenuElementOptionsAndroid {#stackheadertoolbarmenuelementoptionsandroid}
</PlatformHeading>

Options that can be applied to a toolbar menu element via the
`updateToolbarMenuElements` command.

**Extends:** `Partial`\<`Omit`\<[`StackHeaderToolbarMenuItemBaseAndroid`](#stackheadertoolbarmenuitembaseandroid), `"id"`\>\>

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
#### checked {#stackheadertoolbarmenuelementoptionsandroid-checked}
</PlatformHeading>

```ts
checked?: boolean;
```

Sets the checked state of the menu item.

In single-selection groups, setting `checked: true`
automatically unchecks other group members.

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
#### menuTitle {#stackheadertoolbarmenuelementoptionsandroid-menutitle}
</PlatformHeading>

```ts
menuTitle?: string;
```

Sets the header title of a submenu popup.

Only applies to `type: 'menu'` elements. Ignored if the target is a regular
menu item.
