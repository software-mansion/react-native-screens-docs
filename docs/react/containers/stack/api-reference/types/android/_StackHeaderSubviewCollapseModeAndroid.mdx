## StackHeaderSubviewCollapseModeAndroid {#stackheadersubviewcollapsemodeandroid}

> **StackHeaderSubviewCollapseModeAndroid** = `"off"` \| `"parallax"`

Defined in: [components/stack/header/android/StackHeaderSubview.android.types.ts:28](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/header/android/StackHeaderSubview.android.types.ts#L28)

Controls how a stack header subview behaves when the app bar collapses.

The following values are supported:
- `'off'` — the subview scrolls away with the app bar.
- `'parallax'` — the subview scrolls at a slower rate, creating a parallax
  effect.

### Platform

android \>= 21
