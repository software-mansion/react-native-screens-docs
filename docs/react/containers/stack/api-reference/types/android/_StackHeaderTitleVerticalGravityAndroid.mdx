## StackHeaderTitleVerticalGravityAndroid {#stackheadertitleverticalgravityandroid}

> **StackHeaderTitleVerticalGravityAndroid** = `"top"` \| `"center"` \| `"bottom"`

Defined in: [components/stack/header/StackHeaderConfig.android.types.ts:73](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/header/StackHeaderConfig.android.types.ts#L73)

Vertical alignment applied to the app bar title and subtitle.

The following values are supported:
- `'top'` — aligns the text to the top of the app bar.
- `'center'` — centers the text vertically.
- `'bottom'` — aligns the text to the bottom of the app bar.
