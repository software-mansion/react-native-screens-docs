## StackHeaderToolbarMenuAndroid {#stackheadertoolbarmenuandroid}

A submenu element of the toolbar menu, opening a nested popup.

**Extends:** [`StackHeaderToolbarMenuItemBaseAndroid`](#stackheadertoolbarmenuitembaseandroid), [`StackHeaderToolbarMenuBaseAndroid`](#stackheadertoolbarmenubaseandroid)

**Platform:** android \>= 21

### Properties

#### menuTitle? {#stackheadertoolbarmenuandroid-menutitle}

```ts
menuTitle?: string;
```

Header title displayed at the top of the submenu popup.

Maps to Android's `SubMenu.setHeaderTitle()`. This is distinct from
`title`, which controls the label shown in the parent menu's item row.

If `title` is changed by using the `updateToolbarMenuElements` view
command, the menu title will also be changed to the new title (unless the
new title is set to `undefined`). In order to keep the custom menu title,
you should also include `menuTitle` in the view command.

**Platform:** android \>= 21

#### type {#stackheadertoolbarmenuandroid-type}

```ts
type: "menu";
```

Marks this object as a submenu.

Android's `MenuItem` interface claims that nesting submenus isn't supported
but Material's implementation handles it correctly.

**Platform:** android \>= 21
