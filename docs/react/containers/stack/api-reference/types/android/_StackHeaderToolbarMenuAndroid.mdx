Sets the accessibility label (content description) for the menu
element.

the item is placed in the toolbar. There is no default accessibility label

`accessibilityLabel` instead.

#### menuTitle? {#stackheadertoolbarmenuandroid-menutitle}

> `optional` **menuTitle?**: `string`

Defined in: [components/stack/header/StackHeaderConfig.android.types.ts:508](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/header/StackHeaderConfig.android.types.ts#L508)

Header title displayed at the top of the submenu popup.

Maps to Android's `SubMenu.setHeaderTitle()`. This is distinct from
`title`, which controls the label shown in the parent menu's item row.

If `title` is changed by using the `updateToolbarMenuElements` view
command, the menu title will also be changed to the new title (unless the
new title is set to `undefined`). In order to keep the custom menu title,
you should also include `menuTitle` in the view command.

**Platform:** android \>= 21

Specifies whether the element should be displayed as a button in
the Toolbar.

This prop only affects top-level menu elements. Items inside
submenus are always displayed in the popup and ignore this
setting.

Due to native limitations, the width limit for the `'ifRoom'`
options is determined during the initial render and will not
adapt to subsequent layout or orientation changes.

**Default:** `'never'`

**Platform:** android \>= 21
