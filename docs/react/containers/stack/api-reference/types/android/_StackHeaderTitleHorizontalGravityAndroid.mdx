#### StackHeaderTitleHorizontalGravityAndroid {#stackheadertitlehorizontalgravityandroid}
</PlatformHeading>

```ts
type StackHeaderTitleHorizontalGravityAndroid = "start" | "center" | "end";
```

Horizontal alignment applied to the app bar title and subtitle.

The following values are supported:
- `'start'` — aligns the text to the start edge.
- `'center'` — centers the text horizontally.
- `'end'` — aligns the text to the end edge.
