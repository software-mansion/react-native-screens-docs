## StackHeaderTitleHorizontalGravityAndroid {#stackheadertitlehorizontalgravityandroid}

> **StackHeaderTitleHorizontalGravityAndroid** = `"start"` \| `"center"` \| `"end"`

Defined in: [components/stack/header/StackHeaderConfig.android.types.ts:57](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/header/StackHeaderConfig.android.types.ts#L57)

Horizontal alignment applied to the app bar title and subtitle.

The following values are supported:
- `'start'` — aligns the text to the start edge.
- `'center'` — centers the text horizontally.
- `'end'` — aligns the text to the end edge.
