## StackHeaderTypeAndroid {#stackheadertypeandroid}

```ts
type StackHeaderTypeAndroid = "small" | "medium" | "large";
```

Type of the Material 3 app bar.

The following values are supported:
- `'small'` — small app bar with fixed title.
- `'medium'` — medium app bar with collapsing title.
- `'large'` — large app bar with collapsing title.

**Platform:** android \>= 21
