## StackHeaderToolbarMenuItemTypeAndroid {#stackheadertoolbarmenuitemtypeandroid}

> **StackHeaderToolbarMenuItemTypeAndroid** = `"action"` \| `"toggle"` \| `"automatic"`

Defined in: [components/stack/header/StackHeaderConfig.android.types.ts:342](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/header/StackHeaderConfig.android.types.ts#L342)

Controls how a menu item behaves when clicked.

The following values are supported:
- `'action'` — the item fires `onPress` without any toggle state.
- `'toggle'` — the item is checkable; requires `groupId`.
- `'automatic'` — the item becomes checkable if it has a `groupId`, otherwise
  it behaves as an action.

### Platform

android \>= 21
