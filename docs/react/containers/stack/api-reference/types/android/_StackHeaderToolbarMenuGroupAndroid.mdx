#### StackHeaderToolbarMenuGroupAndroid {#stackheadertoolbarmenugroupandroid}
</PlatformHeading>

Group definition enabling selection behavior for toolbar menu items.

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
##### groupId {#stackheadertoolbarmenugroupandroid-groupid}
</PlatformHeading>

```ts
groupId: string;
```

Unique identifier of the group.

Groups enable selection behavior (single-selection / radio, or
multi-toggle). A group is scoped to the menu level it is defined
in — groups cannot span submenus.

Group identifier must be unique across the entire menu tree.

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
##### onSelectionChange {#stackheadertoolbarmenugroupandroid-onselectionchange}
</PlatformHeading>

```ts
onSelectionChange?: StackHeaderMenuSelectionHandler;
```

Callback invoked when the selection within the group changes.

**Type:** [`StackHeaderMenuSelectionHandler`](#stackheadermenuselectionhandler)

<PlatformHeading platforms={[{"platform":"android","from":"21"}]}>
##### singleSelection {#stackheadertoolbarmenugroupandroid-singleselection}
</PlatformHeading>

```ts
singleSelection?: boolean;
```

Determines the type of selection in the group.

When `true`, only one item in the group can be selected
at a time (radio behavior). When `false`, items toggle
independently (checkbox behavior).

**Default:** `false`
