#### StackHeaderItemVisibilityPriorityIOS {#stackheaderitemvisibilitypriorityios}
</ReferenceHeading>

```ts
type StackHeaderItemVisibilityPriorityIOS = "low" | "standard" | "high";
```

Priority used when the header has to decide which items to keep.

The following values are supported:
- `'low'`
- `'standard'`
- `'high'`

**See:** [UIBarButtonItem.visibilityPriority](https://developer.apple.com/documentation/uikit/uibarbuttonitem/visibilitypriority)
