#### StackScreenAnimationFadeFromEdgePresetName {#stackscreenanimationfadefromedgepresetname}
</ReferenceHeading>

```ts
type StackScreenAnimationFadeFromEdgePresetName = "fadeFromBottom" | "fadeFromTop";
```

Names of the [presets](#stackscreenanimationpresetname) that accept
[distance](#stackscreenanimationfadefromedgepresetref-distance) and the
timing options.

The following values are supported:
- `'fadeFromBottom'` — the new screen fades in while rising from slightly
  below; a pop fades it out while it falls.
- `'fadeFromTop'` — the new screen fades in while falling from slightly
  above; a pop fades it out while it rises.
