#### StackScreenAnimationUntimedPresetName {#stackscreenanimationuntimedpresetname}
</ReferenceHeading>

```ts
type StackScreenAnimationUntimedPresetName = "default" | "none";
```

Names of the [presets](#stackscreenanimationpresetname) that accept no
options.

The following values are supported:
- `'default'` — a cross-zoom below API 33 and, from API 33 on, the
  horizontal slide of Android 13, which follows the layout direction.
- `'none'` — no visible animation.
