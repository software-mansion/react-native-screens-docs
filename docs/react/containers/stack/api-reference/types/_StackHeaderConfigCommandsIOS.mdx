##### setMenuItemOptions {#stackheaderconfigcommandsios-setmenuitemoptions}
</ReferenceHeading>

```ts
setMenuItemOptions: (menuElementId: string, options: StackHeaderMenuItemOptionsIOS) => void;
```

Updates properties of a menu action (leaf item) at runtime.

**Parameters:**

- `menuElementId`: `string` — The ID of the menu action to update.
- `options`: [`StackHeaderMenuItemOptionsIOS`](#stackheadermenuitemoptionsios) — Object with properties to change. Omitted keys preserve current values. Explicit `undefined` resets to default.

**Returns:** `void`
