#### StackHeaderToolbarMenuItemAndroid {#stackheadertoolbarmenuitemandroid}
</ReferenceHeading>

Item of the toolbar menu.

Depending on its
[itemType](#stackheadertoolbarmenuitemandroid-itemtype) and
[groupId](#stackheadertoolbarmenuitemandroid-groupid), the item calls
[onPress](#stackheadertoolbarmenuitemandroid-onpress) or toggles its
checked state.

**Extends:** [`StackHeaderToolbarMenuItemBaseAndroid`](#stackheadertoolbarmenuitembaseandroid)

<ReferenceHeading platforms={[{"platform":"android"}]} source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/stack/header/StackHeaderConfig.android.types.ts#L358"}>
##### groupId {#stackheadertoolbarmenuitemandroid-groupid}
</ReferenceHeading>

```ts
groupId?: string;
```

Assigns this item to a group.

Groups enable selection behavior (single-selection / radio, or
multi-toggle). A group is scoped to the menu level it is defined in —
groups cannot span submenus.

Required when `itemType` is `'toggle'`. Cannot be set when `itemType` is
`'action'`.

<ReferenceHeading platforms={[{"platform":"android"}]} source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/stack/header/StackHeaderConfig.android.types.ts#L389"}>
##### initialToggleState {#stackheadertoolbarmenuitemandroid-initialtogglestate}
</ReferenceHeading>

```ts
initialToggleState?: boolean;
```

Initial checked state for toggle items.

Only meaningful when effective `itemType` is `'toggle'`.

The initial state does not trigger
[onSelectionChange](#stackheadertoolbarmenugroupandroid-onselectionchange)
on the group at mount time.

A [toolbarMenu](#header-config-android-toolbarmenu) prop
change restores the selection to this value. Neither that restore nor a
native header rebuild triggers `onSelectionChange`.

**Default:** `false`

<ReferenceHeading platforms={[{"platform":"android"}]} source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/stack/header/StackHeaderConfig.android.types.ts#L371"}>
##### itemType {#stackheadertoolbarmenuitemandroid-itemtype}
</ReferenceHeading>

```ts
itemType?: StackHeaderToolbarMenuItemTypeAndroid;
```

Controls how the item behaves when clicked.

**Type:** [`StackHeaderToolbarMenuItemTypeAndroid`](#stackheadertoolbarmenuitemtypeandroid)

:::note

If `'toggle'` menu item is shown in the toolbar by setting
[showAsAction](#stackheadertoolbarmenuitembaseandroid-showasaction)
prop to value other than `'never'`, there is no visual indication of the
item toggle state.

:::

**Default:** `'automatic'`

##### onPress {#stackheadertoolbarmenuitemandroid-onpress}
</ReferenceHeading>

```ts
onPress?: StackHeaderPressHandler;
```

Callback invoked when the menu item is pressed.

Not called for items that behave as toggles (items with a `groupId` or
`itemType: 'toggle'`). For those items, use
[onSelectionChange](#stackheadertoolbarmenugroupandroid-onselectionchange)
on the group instead.

**Type:** [`StackHeaderPressHandler`](#stackheaderpresshandler)
