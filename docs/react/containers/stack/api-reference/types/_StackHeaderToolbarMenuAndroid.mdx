##### menuTitle {#stackheadertoolbarmenuandroid-menutitle}
</ReferenceHeading>

```ts
menuTitle?: string;
```

Header title displayed at the top of the submenu popup.

This is distinct from `title`, which controls the label shown in the parent
menu's item row.

When left unset, the header falls back to `title`; when both are unset,
the popup shows no header.

**See:** [SubMenu.setHeaderTitle](https://developer.android.com/reference/android/view/SubMenu#setHeaderTitle(java.lang.CharSequence))

Marks this object as a submenu.

This is an implementation detail and may change. Android's `MenuItem`
interface claims that nesting submenus isn't supported but Material's
implementation handles it correctly.
