Submenu of the toolbar menu.

Pressing a submenu opens a popup with its own elements.

<ReferenceHeading platforms={[{"platform":"android"}]} source={"src/components/stack/header/StackHeaderConfig.android.types.ts#L502"}>
##### menuTitle {#stackheadertoolbarmenuandroid-menutitle}
</ReferenceHeading>

```ts
menuTitle?: string;
```

Header title displayed at the top of the submenu popup.

This is distinct from
[title](#stackheadertoolbarmenuitembaseandroid-title), which controls
the label shown in the parent menu's item row.

**Default:** The header falls back to `title`; when both are unset, the popup shows no header.

**See:** [SubMenu.setHeaderTitle](https://developer.android.com/reference/android/view/SubMenu#setHeaderTitle(java.lang.CharSequence))
