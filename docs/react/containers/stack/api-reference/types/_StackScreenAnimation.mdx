#### StackScreenAnimation {#stackscreenanimation}
</ReferenceHeading>

```ts
type StackScreenAnimation = StackScreenAnimationPresetName | StackScreenAnimationPresetRef;
```

Transition of a [Stack.Screen](#screen).

The following values are supported:
- a [StackScreenAnimationPresetName](#stackscreenanimationpresetname) — the preset with its own
  timing.
- a [StackScreenAnimationPresetRef](#stackscreenanimationpresetref) — the preset with options.

**Type:** [`StackScreenAnimationPresetName`](#stackscreenanimationpresetname) \| [`StackScreenAnimationPresetRef`](#stackscreenanimationpresetref)
