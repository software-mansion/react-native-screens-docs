#### StackHeaderItemIOS {#stackheaderitemios}
</ReferenceHeading>

```ts
type StackHeaderItemIOS =
  | StackHeaderButtonItemIOS
  | StackHeaderCustomItemIOS
  | StackHeaderSpacerItemIOS;
```

Item that can be placed in
[leadingItems](#header-config-ios-leadingitems) and
[trailingItems](#header-config-ios-trailingitems).

The kind of the item, and with it the set of supported props, is selected
with `type`:
- `'button'` — [StackHeaderButtonItemIOS](#stackheaderbuttonitemios),
- `'custom'` — [StackHeaderCustomItemIOS](#stackheadercustomitemios),
- `'spacer'` — [StackHeaderSpacerItemIOS](#stackheaderspaceritemios), further distinguished by
  `sizing`.
