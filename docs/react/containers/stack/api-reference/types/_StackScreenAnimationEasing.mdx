#### StackScreenAnimationEasing {#stackscreenanimationeasing}
</ReferenceHeading>

```ts
type StackScreenAnimationEasing = StackScreenAnimationEasingName | StackScreenAnimationBezier;
```

A named curve or a cubic bezier `[x1, y1, x2, y2]` with `x1`, `x2` in
`[0, 1]`.

**Type:** [`StackScreenAnimationEasingName`](#stackscreenanimationeasingname) \| [`StackScreenAnimationBezier`](#stackscreenanimationbezier)
