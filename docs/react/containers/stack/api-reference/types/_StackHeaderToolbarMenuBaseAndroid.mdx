##### groups {#stackheadertoolbarmenubaseandroid-groups}
</ReferenceHeading>

```ts
groups?: StackHeaderToolbarMenuGroupAndroid[];
```

Group definitions for items in this menu level.

Groups enable selection behavior (single or multi-toggle) for items that
share the same [groupId](#stackheadertoolbarmenuitemandroid-groupid).
A group is scoped to the menu level it is defined in — groups cannot span
submenus.

**Type:** [`StackHeaderToolbarMenuGroupAndroid[]`](#stackheadertoolbarmenugroupandroid)
