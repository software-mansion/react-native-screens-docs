##### accessibilityLabel {#stackheadertoolbarmenuitembaseandroid-accessibilitylabel}
</ReferenceHeading>

```ts
accessibilityLabel?: string;
```

Sets the accessibility label (content description) for the menu
element.

When `undefined`, Android uses the `title` for the accessibility label when
the item is placed in the toolbar. There is no default accessibility label
for items inside overflow menu/submenus.

Due to native platform limitations, it's not possible to provide `testID`
for menu items inside overflow menu/submenus. If possible, use
`accessibilityLabel` instead.

##### icon {#stackheadertoolbarmenuitembaseandroid-icon}
</ReferenceHeading>

```ts
icon?: PlatformIconAndroid;
```

Specifies the icon for the menu element.

Note that `'imageSource'` doesn't support SVGs on Android; use `'drawableResource'`,
which requires adding a drawable to resources via Android Studio.

The icon will be visible only if the menu element is shown in the
Toolbar.

**Type:** [`PlatformIconAndroid`](../../../../common-types/index.mdx#platformiconandroid)

##### showAsAction {#stackheadertoolbarmenuitembaseandroid-showasaction}
</ReferenceHeading>

```ts
showAsAction?: StackHeaderToolbarMenuItemShowAsActionAndroid;
```

Specifies whether the element should be displayed as a button in
the Toolbar.

This prop only affects top-level menu elements. Items inside
submenus are always displayed in the popup and ignore this
setting.

Due to native limitations, the width limit for the `'ifRoom'`
options is determined during the initial render and will not
adapt to subsequent layout or orientation changes.

**Type:** [`StackHeaderToolbarMenuItemShowAsActionAndroid`](#stackheadertoolbarmenuitemshowasactionandroid)

**Default:** `'never'`

##### title {#stackheadertoolbarmenuitembaseandroid-title}
</ReferenceHeading>

```ts
title?: string;
```

Title of the menu element.

If `title` is changed for the element of type `'menu'` by using the
`updateToolbarMenuElements` view command, the menu title (`menuTitle`)
will also be changed to the new title (unless the new title is set to
`undefined`). In order to keep the custom menu title, you should also
include `menuTitle` in the view command.

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/stack/header/StackHeaderConfig.android.types.ts#L174"}>
##### titleCondensed {#stackheadertoolbarmenuitembaseandroid-titlecondensed}
</ReferenceHeading>

```ts
titleCondensed?: string;
```

Shorter title used for the menu element when it is displayed as
a button in the Toolbar.

When the element is shown in the Toolbar with a text label, this
condensed title is used instead of `title`. The full `title` is still
used everywhere else (the overflow menu and submenus).
