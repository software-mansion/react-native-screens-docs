#### StackHeaderMinimizationBehaviorIOS {#stackheaderminimizationbehaviorios}
</ReferenceHeading>

```ts
type StackHeaderMinimizationBehaviorIOS = "automatic" | "never" | "onScrollDown" | "onScrollUp";
```

Controls when the navigation bar minimizes in response to scrolling.

The following values are supported:
- `'automatic'` — the system determines the minimization behavior.
- `'never'` — the navigation bar does not minimize.
- `'onScrollDown'` — the navigation bar minimizes when the user scrolls
  down.
- `'onScrollUp'` — the navigation bar minimizes when the user scrolls up.
