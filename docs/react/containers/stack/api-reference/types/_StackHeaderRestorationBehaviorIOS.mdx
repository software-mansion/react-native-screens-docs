#### StackHeaderRestorationBehaviorIOS {#stackheaderrestorationbehaviorios}
</ReferenceHeading>

```ts
type StackHeaderRestorationBehaviorIOS = "automatic" | "atScrollEdge";
```

Controls when a minimized navigation bar restores.

The following values are supported:
- `'automatic'` — the system determines the restoration behavior. By
  default the navigation bar restores when the user reverses scroll
  direction.
- `'atScrollEdge'` — the navigation bar restores only when the scroll
  view's content reaches the scroll edge. Honored only together with
  `minimizationBehavior: 'onScrollDown'`.
