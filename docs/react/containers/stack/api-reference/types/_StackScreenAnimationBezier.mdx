#### StackScreenAnimationBezier {#stackscreenanimationbezier}
</ReferenceHeading>

```ts
type StackScreenAnimationBezier = [number, number, number, number];
```

Cubic bezier curve `[x1, y1, x2, y2]`.

`x1` and `x2` must be in `[0, 1]`. `y1` and `y2` may be outside it, which
makes the curve overshoot.
