A flexible-size spacer item for visual separation of header items.

### Remarks

Separates items defined in [leadingItems](#stackheaderconfigpropsios-leadingitems)
and [trailingItems](#stackheaderconfigpropsios-trailingitems).
For iOS 26 it splits liquid glass bubble for two adjacent items.
