## StackHeaderFlexibleSpacerItemIOS {#stackheaderflexiblespaceritemios}

A flexible-size spacer item for visual separation of header items.

Separates items defined in [leadingItems](#header-config-ios-leadingitems)
and [trailingItems](#header-config-ios-trailingitems).
For iOS 26 it splits liquid glass bubble for two adjacent items.

**Platform:** ios \>= 13

### Properties

#### id {#stackheaderflexiblespaceritemios-id}

```ts
id: string;
```

A unique identifier within the screen header.

**Platform:** ios \>= 13

#### sizing {#stackheaderflexiblespaceritemios-sizing}

```ts
sizing: "flexible";
```

Marks this object as a flexible-size spacer definition.

**Platform:** ios \>= 13

#### type {#stackheaderflexiblespaceritemios-type}

```ts
type: "spacer";
```

Marks this object as a spacer definition.

**Platform:** ios \>= 13
