## StackHeaderInlineItemIOS {#stackheaderinlineitemios}

Native header item with text label.

**Platform:** ios \>= 13

### Properties

#### icon? {#stackheaderinlineitemios-icon}

```ts
icon?: PlatformIconIOS;
```

Icon displayed for the header item.

For async image sources, the item renders without an icon first and updates when
loaded. Ignored when custom view ([render](#stackheaderinlinecustomitemios-render)) is
set.

**Type:** [`PlatformIconIOS`](../../../../../common-types/index.mdx#platformiconios)

**Platform:** ios \>= 13

#### id {#stackheaderinlineitemios-id}

```ts
id: string;
```

A unique identifier within the screen header.

**Platform:** ios \>= 13

#### identifier? {#stackheaderinlineitemios-identifier}

```ts
identifier?: string;
```

Stable identifier used to match the item across different screens for
more intelligent animation on transition.

When navigating between screens, iOS tries to match similarly looking
items (i.e. same sfSymbol) and animate between them. If the heuristic
fails, a simpler crossfade is applied. In a situation where visually
different items should be logically considered the same across screens,
you may use this prop to tell this fact to the system. The identifier
shouldn't be updated at runtime; doing so will result in item rebuild and
visual flash.

**Platform:** ios \>= 26

#### menu? {#stackheaderinlineitemios-menu}

```ts

```

Menu definition for the context menu that appears when item is tapped.

**Type:** [`StackHeaderMenuIOS`](#stackheadermenuios)

#### onPress? {#stackheaderinlineitemios-onpress}

```ts
onPress?: StackHeaderPressHandler;
```

Callback invoked when the header item is pressed.

Fires when the user taps the header item. When combined with
[menu](#stackheaderinlineitemios-menu), tapping fires `onPress` and
long-pressing shows the menu.

**Type:** [`StackHeaderPressHandler`](#stackheaderpresshandler)

**Platform:** ios \>= 13

A title for the item that is displayed in the header.
