#### StackHeaderItemIOS {#stackheaderitemios}
</ReferenceHeading>

```ts
type StackHeaderItemIOS =
  | StackHeaderInlineItemIOS
  | StackHeaderInlineCustomItemIOS
  | StackHeaderSpacerItemIOS;
```

A header item placed in [leadingItems](#header-config-ios-leadingitems) or
[trailingItems](#header-config-ios-trailingitems).

The following variants are supported:
- [StackHeaderInlineItemIOS](#stackheaderinlineitemios) — a native item with a text label.
- [StackHeaderInlineCustomItemIOS](#stackheaderinlinecustomitemios) — an item with a custom view.
- [StackHeaderSpacerItemIOS](#stackheaderspaceritemios) — a spacer used for visual separation.

**Type:** [`StackHeaderInlineItemIOS`](#stackheaderinlineitemios) \| [`StackHeaderInlineCustomItemIOS`](#stackheaderinlinecustomitemios) \| [`StackHeaderSpacerItemIOS`](#stackheaderspaceritemios)
