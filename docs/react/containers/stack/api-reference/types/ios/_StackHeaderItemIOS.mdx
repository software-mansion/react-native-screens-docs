## StackHeaderItemIOS {#stackheaderitemios}

> **StackHeaderItemIOS** = [`StackHeaderInlineItemIOS`](#stackheaderinlineitemios) \| [`StackHeaderInlineCustomItemIOS`](#stackheaderinlinecustomitemios) \| [`StackHeaderSpacerItemIOS`](#stackheaderspaceritemios)

Defined in: [components/stack/header/StackHeaderConfig.ios.types.ts:365](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/header/StackHeaderConfig.ios.types.ts#L365)

A header item placed in [leadingItems](#stackheaderconfigpropsios-leadingitems) or
[trailingItems](#stackheaderconfigpropsios-trailingitems).

The following variants are supported:
- [StackHeaderInlineItemIOS](#stackheaderinlineitemios) — a native item with a text label.
- [StackHeaderInlineCustomItemIOS](#stackheaderinlinecustomitemios) — an item with a custom view.
- [StackHeaderSpacerItemIOS](#stackheaderspaceritemios) — a spacer used for visual separation.
