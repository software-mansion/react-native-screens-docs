## StackHeaderMenuElementIOS {#stackheadermenuelementios}

```ts
type StackHeaderMenuElementIOS = StackHeaderMenuIOS | StackHeaderMenuItemIOS;
```

A menu element type.

A menu element is either a [menu](#stackheadermenuios) (container with
children) or a [menu item](#stackheadermenuitemios) (actionable leaf).

**Type:** [`StackHeaderMenuIOS`](#stackheadermenuios) \| [`StackHeaderMenuItemIOS`](#stackheadermenuitemios)

**Platform:** ios \>= 13
