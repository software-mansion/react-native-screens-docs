```ts
type StackHeaderSpacerItemIOS = StackHeaderFixedSpacerItemIOS | StackHeaderFlexibleSpacerItemIOS;
```

A header spacer item.

The following variants are supported:
- [StackHeaderFixedSpacerItemIOS](#stackheaderfixedspaceritemios) — a fixed-width spacer.
- [StackHeaderFlexibleSpacerItemIOS](#stackheaderflexiblespaceritemios) — a flexible spacer.

**Type:** [`StackHeaderFixedSpacerItemIOS`](#stackheaderfixedspaceritemios) \| [`StackHeaderFlexibleSpacerItemIOS`](#stackheaderflexiblespaceritemios)
