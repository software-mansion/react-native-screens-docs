## StackHeaderMenuItemIOS {#stackheadermenuitemios}

Represents a single actionable item inside a [StackHeaderMenuIOS](#stackheadermenuios) menu.

A menu item is a leaf element that the user can interact with.
Depending on its [itemType](#stackheadermenuitemios-itemtype), the item
behaves as a one-shot action or a stateful toggle.

**Platform:** ios \>= 13

### Properties

#### icon? {#stackheadermenuitemios-icon}

```ts
icon?: PlatformIconIOS;
```

Icon displayed for the menu item.

For async image sources, the menu item renders without an icon first and updates
when loaded.

**Type:** [`PlatformIconIOS`](../../../../../common-types/index.mdx#platformiconios)

**Platform:** ios \>= 13

#### id {#stackheadermenuitemios-id}

```ts
id: string;
```

Unique identifier of the menu item.

Used to locate the item inside a menu tree and to identify selected items
in [StackHeaderMenuIOS.onSelectionChange](#stackheadermenuios-onselectionchange) callback.

**Platform:** ios \>= 13

#### initialToggleState? {#stackheadermenuitemios-initialtogglestate}

```ts
initialToggleState?: boolean;
```

Initial on/off state of a toggle item.

Only meaningful when [itemType](#stackheadermenuitemios-itemtype)
resolves to `'toggle'`. Inside a `singleSelection` hierarchy, at most one
item can set this to `true`.

**Default:** `false`

**Platform:** ios \>= 13

#### itemType? {#stackheadermenuitemios-itemtype}

```ts
itemType?: StackHeaderMenuItemTypeIOS;
```

Determines the behavior of the menu item.

**Type:** [`StackHeaderMenuItemTypeIOS`](#stackheadermenuitemtypeios)

**Default:** `'automatic'`

**Platform:** ios \>= 13

#### keepsMenuPresented? {#stackheadermenuitemios-keepsmenupresented}

```ts
keepsMenuPresented?: boolean;
```

Keeps the menu presented after this item is tapped.

When enabled, selecting this item will not dismiss the menu,
allowing the user to continue interacting with other items.

This prop should only be used for items in top-level menus.

**Default:** `false`

**Platform:** ios \>= 16

#### onPress? {#stackheadermenuitemios-onpress}

```ts
onPress?: StackHeaderPressHandler;
```

Callback invoked when the menu item is pressed.

Fires only for items whose effective type is `'action'`. For toggle items,
this callback will not fire — use
[onSelectionChange](#stackheadermenuios-onselectionchange) on the
parent menu instead.

**Type:** [`StackHeaderPressHandler`](#stackheaderpresshandler)

**Platform:** ios \>= 13

#### title? {#stackheadermenuitemios-title}

```ts
title?: string;
```

Title displayed for the menu item.

**Platform:** ios \>= 13

#### type {#stackheadermenuitemios-type}

```ts
type: "menuItem";
```

Marks this object as a menu item definition.

**Platform:** ios \>= 13
