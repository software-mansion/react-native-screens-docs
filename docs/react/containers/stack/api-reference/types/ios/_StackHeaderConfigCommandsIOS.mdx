## StackHeaderConfigCommandsIOS {#stackheaderconfigcommandsios}

Imperative commands for the iOS header configuration.

**Platform:** ios \>= 13

### Properties

#### setMenuItemOptions {#stackheaderconfigcommandsios-setmenuitemoptions}

```ts
setMenuItemOptions: (menuElementId: string, options: StackHeaderMenuItemOptionsIOS) => void;
```

Updates properties of a menu action (leaf item) at runtime.

**Platform:** ios \>= 13

**Parameters:**

- `menuElementId`: `string` — The ID of the menu action to update.
- `options`: [`StackHeaderMenuItemOptionsIOS`](#stackheadermenuitemoptionsios) — Object with properties to change. Omitted keys preserve current values. Explicit `undefined` resets to default.

**Returns:** `void`

#### setMenuOptions {#stackheaderconfigcommandsios-setmenuoptions}

```ts
setMenuOptions: (menuElementId: string, options: StackHeaderMenuOptionsIOS) => void;
```

Updates properties of a submenu at runtime.

**Platform:** ios \>= 13

**Parameters:**

- `menuElementId`: `string` — The ID of the submenu to update.
- `options`: [`StackHeaderMenuOptionsIOS`](#stackheadermenuoptionsios) — Object with properties to change. Omitted keys preserve current values. Explicit `undefined` resets to default.

**Returns:** `void`
