## StackHeaderMenuItemOptionsIOS {#stackheadermenuitemoptionsios}
</PlatformHeading>

Options for updating a menu action (leaf item) at runtime.

Omitted keys preserve current values. Explicit `undefined` resets to default.

<PlatformHeading platforms={[{"platform":"ios","from":"13"}]}>
#### icon {#stackheadermenuitemoptionsios-icon}
</PlatformHeading>

```ts
icon?: PlatformIconIOS;
```

New icon for the menu action.

**Type:** [`PlatformIconIOS`](../../../../../common-types/index.mdx#platformiconios)

<PlatformHeading platforms={[{"platform":"ios","from":"13"}]}>
#### title {#stackheadermenuitemoptionsios-title}
</PlatformHeading>

```ts
title?: string;
```

New title for the menu action.

<PlatformHeading platforms={[{"platform":"ios","from":"13"}]}>
#### toggleState {#stackheadermenuitemoptionsios-togglestate}
</PlatformHeading>

```ts
toggleState?: boolean;
```

Sets the toggle state of the menu item.

When inside a single selection hierarchy, setting `true` deselects the
previously selected item and selects this one. Setting `false` is a noop
in this case - only has effect for regular toggles.
