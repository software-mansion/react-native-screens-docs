## StackHeaderFixedSpacerItemIOS {#stackheaderfixedspaceritemios}

A fixed-size spacer item for visual separation of header items.

Separates items defined in [leadingItems](#header-config-ios-leadingitems)
and [trailingItems](#header-config-ios-trailingitems). The fixed size spacing works
for iOS 18 and below, for iOS 26 it only splits liquid glass bubble for two adjacent items.

**Platform:** ios \>= 13

### Properties

#### id {#stackheaderfixedspaceritemios-id}

```ts
id: string;
```

A unique identifier within the screen header.

**Platform:** ios \>= 13

#### sizing {#stackheaderfixedspaceritemios-sizing}

```ts
sizing: "fixed";
```

Marks this object as a fixed-size spacer definition.

**Platform:** ios \>= 13

#### type {#stackheaderfixedspaceritemios-type}

```ts
type: "spacer";
```

Marks this object as a spacer definition.

**Platform:** ios \>= 13

#### width {#stackheaderfixedspaceritemios-width}

```ts
width: number;
```

Specifies space width between adjacent header items.

**Platform:** ios \>= 13
