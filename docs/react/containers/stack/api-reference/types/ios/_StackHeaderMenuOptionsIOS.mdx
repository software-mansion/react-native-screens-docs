## StackHeaderMenuOptionsIOS {#stackheadermenuoptionsios}

Options for updating a submenu at runtime.

Omitted keys preserve current values. Explicit `undefined` resets to default.

**Platform:** ios \>= 13

### Properties

#### icon? {#stackheadermenuoptionsios-icon}

```ts
icon?: PlatformIconIOS;
```

New icon for the submenu.

**Type:** [`PlatformIconIOS`](../../../../../common-types/index.mdx#platformiconios)

**Platform:** ios \>= 13

#### title? {#stackheadermenuoptionsios-title}

```ts
title?: string;
```

New title for the submenu.

**Platform:** ios \>= 13
