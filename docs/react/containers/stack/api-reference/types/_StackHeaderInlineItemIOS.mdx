##### disabled {#stackheaderinlineitemios-disabled}
</ReferenceHeading>

```ts
disabled?: boolean;
```

Whether the item is disabled.

A disabled item is grayed out and does not respond to user interaction:
neither [onPress](#stackheaderinlineitemios-onpress) nor
[menu](#supportsmenuios-menu) is triggered.

**Default:** `false`

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/stack/header/StackHeaderConfig.ios.types.ts#L231"}>
##### onPress {#stackheaderinlineitemios-onpress}
</ReferenceHeading>

```ts
onPress?: StackHeaderPressHandler;
```

Callback invoked when the header item is pressed.

Fires when the user taps the header item. When combined with
[menu](#supportsmenuios-menu), tapping fires `onPress` and
long-pressing shows the menu.

**Type:** [`StackHeaderPressHandler`](#stackheaderpresshandler)

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/stack/header/StackHeaderConfig.ios.types.ts#L211"}>
##### tintColor {#stackheaderinlineitemios-tintcolor}
</ReferenceHeading>

```ts
tintColor?: ColorValue;
```

Tint color of the item.

Applied to the item's title and icon. For `'prominent'` items on iOS 26,
the tint affects the emphasized background instead.

When unset, the item uses the default system tint.
