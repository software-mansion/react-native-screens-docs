#### StackHeaderToolbarMenuItemTypeAndroid {#stackheadertoolbarmenuitemtypeandroid}
</ReferenceHeading>

```ts
type StackHeaderToolbarMenuItemTypeAndroid = "action" | "toggle" | "automatic";
```

How a menu item behaves when clicked.

The following values are available:
- `'action'` — the item fires
  [onPress](#stackheadertoolbarmenuitemandroid-onpress) without any
  toggle state,
- `'toggle'` — the item is checkable; requires
  [groupId](#stackheadertoolbarmenuitemandroid-groupid),
- `'automatic'` — the item becomes checkable if it has a `groupId`, otherwise
  it behaves as an action.
