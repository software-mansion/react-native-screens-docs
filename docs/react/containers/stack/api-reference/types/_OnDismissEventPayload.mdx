#### OnDismissEventPayload {#ondismisseventpayload}
</ReferenceHeading>

```ts
type OnDismissEventPayload = {
  isNativeDismiss: boolean;
};
```

Payload of the native dismiss event.

:::note

This is an implementation detail and may change. [Stack.Screen](#screen) turns
this event into a call of `onDismiss` or `onNativeDismiss`.

:::

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/stack/screen/StackScreen.types.ts#L17"}>
##### isNativeDismiss {#ondismisseventpayload-isnativedismiss}
</ReferenceHeading>

```ts
isNativeDismiss: boolean;
```

Whether the user dismissed the screen natively (`true`) or the screen was
popped because its `activityMode` became `'detached'` (`false`).
