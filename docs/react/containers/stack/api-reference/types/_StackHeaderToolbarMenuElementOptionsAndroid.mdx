##### checked {#stackheadertoolbarmenuelementoptionsandroid-checked}
</ReferenceHeading>

```ts
checked?: boolean;
```

Sets the checked state of the menu item.

In single-selection groups, setting `checked: true` automatically unchecks
other group members.

##### menuTitle {#stackheadertoolbarmenuelementoptionsandroid-menutitle}
</ReferenceHeading>

```ts
menuTitle?: string;
```

Sets the header title of a submenu popup.

Only applies to `type: 'menu'` elements. Ignored if the target is a regular
menu item. Setting it to `undefined` drops the
[menuTitle](#stackheadertoolbarmenuandroid-menutitle) prop as well,
leaving the header to fall back to
[title](#stackheadertoolbarmenuitembaseandroid-title).
