## StackHeaderMenuSelectionHandler {#stackheadermenuselectionhandler}

```ts
type StackHeaderMenuSelectionHandler = (selectedMenuElementIds: string[]) => void;
```

Handler invoked when the selection within a header menu changes.

The platforms scope it differently — see
[StackHeaderMenuSelectionHandlerIOS](#stackheadermenuselectionhandlerios) and
[StackHeaderToolbarMenuSelectionHandlerAndroid](#stackheadertoolbarmenuselectionhandlerandroid); this shared type
carries the common shape.

**Platform:** android \>= 21, ios \>= 13

**Parameters:**

- `selectedMenuElementIds`: `string[]` — IDs of the currently selected toggle items.

**Returns:** `void`
