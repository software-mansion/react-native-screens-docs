## StackScreenDismissHandler {#stackscreendismisshandler}

```ts
type StackScreenDismissHandler = (screenKey: string) => void;
```

Handler invoked when a stack screen is dismissed.

**Platform:** android \>= 21, ios \>= 13

**Parameters:**

- `screenKey`: `string` — Key of the dismissed screen.

**Returns:** `void`
