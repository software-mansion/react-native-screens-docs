## OnDismissEventPayload {#ondismisseventpayload}

```ts
type OnDismissEventPayload = {
  isNativeDismiss: boolean;
};
```

Payload of the event emitted when a stack screen is dismissed.

**Platform:** android \>= 21, ios \>= 13

### Properties

#### isNativeDismiss {#ondismisseventpayload-isnativedismiss}

```ts
isNativeDismiss: boolean;
```

Whether the dismissal was initiated natively (e.g. a swipe-back gesture).

**Platform:** android \>= 21, ios \>= 13
