## StackScreenActivityMode {#stackscreenactivitymode}

> **StackScreenActivityMode** = `"detached"` \| `"attached"`

Defined in: [components/stack/screen/StackScreen.types.ts:39](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/screen/StackScreen.types.ts#L39)

Activity mode of a stack screen.

The following values are supported:
- `'detached'` — the screen is detached from the native view hierarchy.
- `'attached'` — the screen is attached to the native view hierarchy.

android, ios
