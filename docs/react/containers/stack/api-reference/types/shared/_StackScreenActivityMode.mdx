## StackScreenActivityMode {#stackscreenactivitymode}
</PlatformHeading>

```ts
type StackScreenActivityMode = "detached" | "attached";
```

Activity mode of a stack screen.

The following values are supported:
- `'detached'` — the screen is detached from the native view hierarchy.
- `'attached'` — the screen is attached to the native view hierarchy.
