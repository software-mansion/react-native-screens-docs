##### menuRepresentation {#supportsmenuios-menurepresentation}
</ReferenceHeading>

```ts
menuRepresentation?: StackHeaderMenuIOS;
```

Menu definition substituting the item when it is displayed in a menu.

When the system moves the item into a menu (e.g. the navigation bar
overflow menu), this menu is displayed in its place. Useful for custom
items ([render](#stackheaderinlinecustomitemios-render)), which iOS
doesn't display in the overflow menu otherwise.
The `id`s used in the menu are expected to be unique across every `menu`
and `menuRepresentation`.

**Type:** [`StackHeaderMenuIOS`](#stackheadermenuios)
