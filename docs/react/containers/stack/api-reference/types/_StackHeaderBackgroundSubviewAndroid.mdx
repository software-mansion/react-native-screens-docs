##### collapseMode {#stackheaderbackgroundsubviewandroid-collapsemode}
</ReferenceHeading>

```ts
collapseMode?: StackHeaderBackgroundSubviewCollapseModeAndroid;
```

Controls how the background subview behaves when the app bar collapses.

**Type:** [`StackHeaderBackgroundSubviewCollapseModeAndroid`](#stackheaderbackgroundsubviewcollapsemodeandroid)

:::note

This is an implementation detail and may change. `pin` is not currently
supported because the background subview is stretched to match the entire
`AppBarLayout`, which causes pinned content to move immediately rather than
staying fixed. Support for `pin` collapse mode might be added in the
future.

:::

**Default:** `'off'`

##### render {#stackheaderbackgroundsubviewandroid-render}
</ReferenceHeading>

```ts
render: StackHeaderElementFactory;
```

Render callback for the React element used as the header background.

The subview is stretched to match the header (`AppBarLayout`) dimensions,
so parent-relative sizing (e.g. `flex: 1`) works correctly.

**Type:** [`StackHeaderElementFactory`](#stackheaderelementfactory)
