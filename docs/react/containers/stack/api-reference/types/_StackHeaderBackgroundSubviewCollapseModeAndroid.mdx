#### StackHeaderBackgroundSubviewCollapseModeAndroid {#stackheaderbackgroundsubviewcollapsemodeandroid}
</ReferenceHeading>

```ts
type StackHeaderBackgroundSubviewCollapseModeAndroid = "off" | "parallax";
```

Behavior of the background subview when the app bar collapses.

The following values are available:
- `'off'` - the subview scrolls away with the app bar,
- `'parallax'` - the subview scrolls at a slower rate, creating a parallax
  effect.
