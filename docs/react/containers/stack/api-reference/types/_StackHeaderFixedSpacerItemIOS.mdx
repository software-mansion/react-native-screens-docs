#### StackHeaderFixedSpacerItemIOS {#stackheaderfixedspaceritemios}
</ReferenceHeading>

A spacer item for visual separation of items.

Separates items defined in
[leadingItems](#header-config-ios-leadingitems)
and [trailingItems](#header-config-ios-trailingitems). The
fixed size spacing works for iOS 18 and below, for iOS 26 it only splits
liquid glass bubble for two adjacent items.
