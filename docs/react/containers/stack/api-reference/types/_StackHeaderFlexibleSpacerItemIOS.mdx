#### StackHeaderFlexibleSpacerItemIOS {#stackheaderflexiblespaceritemios}
</ReferenceHeading>

A spacer item for visual separation of items.

Separates items defined in
[leadingItems](#header-config-ios-leadingitems)
and [trailingItems](#header-config-ios-trailingitems).
For iOS 26 it splits liquid glass bubble for two adjacent items.
