#### StackHeaderMenuItemTypeIOS {#stackheadermenuitemtypeios}
</ReferenceHeading>

```ts
type StackHeaderMenuItemTypeIOS = "action" | "toggle" | "automatic";
```

Behavior of a menu item.

The following values are supported:
- `'action'` — a button that fires
  [onPress](#stackheadermenuitemios-onpress) when tapped. Cannot be
  used inside a `singleSelection` menu.
- `'toggle'` — a stateful item whose on/off state is tracked automatically.
  Toggle items do not fire `onPress`; instead, parent menu
  (or Single Selection Root in case of
  [singleSelection](#stackheadermenuios-singleselection))
  is passed currently selected items with
  [onSelectionChange](#stackheadermenuios-onselectionchange)
- `'automatic'` — resolved at render time: becomes `'toggle'` when the item
  is under `singleSelection` hierarchy, `'action'` otherwise.
