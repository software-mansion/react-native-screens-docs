#### StackHeaderTitleVerticalGravityAndroid {#stackheadertitleverticalgravityandroid}
</ReferenceHeading>

```ts
type StackHeaderTitleVerticalGravityAndroid = "top" | "center" | "bottom";
```

Vertical alignment of the title and the subtitle of a `'medium'` or
`'large'` header.

The following values are supported:
- `'top'`
- `'center'`
- `'bottom'`
