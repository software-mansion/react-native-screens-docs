#### transparent? {#header-config-transparent}

> `optional` **transparent?**: `boolean`

Defined in: [components/stack/header/StackHeaderConfig.types.ts:86](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/stack/header/StackHeaderConfig.types.ts#L86)

Specifies if the content should be rendered behind the header.

##### Remarks

When `true`, content is rendered behind the header instead of starting
below it.

On Android:
- The header background color is not affected by this prop.
- Setting this prop to `true` is not supported when header scrolling is
  enabled.

##### Default Value

`false`

##### Platform

android, ios

##### Since

5.0
