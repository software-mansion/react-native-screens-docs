#### ios.largeSubtitle {#header-config-ios-largesubtitle}
</PlatformHeading>

```ts
largeSubtitle?: string;
```

Large subtitle text, displayed when `largeTitleEnabled = true`.

When ScrollView is present on the screen, large header is displayed only when
fully scrolled to top, otherwise it collapses to regular header. If `largeSubititle` is not defined,
it falls back to regular subtitle.

</PlatformHeading>

```ts
largeSubtitleItem?: StackHeaderTitleCustomItemIOS;
```

Custom item to display as a subtitle for large header. Takes precedence over largeSubtitle text.

**Type:** [`StackHeaderTitleCustomItemIOS`](#stackheadertitlecustomitemios)

<PlatformHeading platforms={[{"platform":"ios","from":"13"}]}>
#### ios.leadingItems {#header-config-ios-leadingitems}
</PlatformHeading>

```ts
leadingItems?: StackHeaderItemIOS[];
```

A list of items placed starting from the leading edge.

Items are placed next to the back button, if present. If there
is not enough space to fit all leading items at once, they are all moved to
overflow menu. This differs from trailing items, which are moved one by one.

Note: Custom items are not put into the overflow menu, but are removed entirely.

**Type:** [`StackHeaderItemIOS[]`](#stackheaderitemios)

<PlatformHeading platforms={[{"platform":"ios","from":"16"}]}>
#### ios.titleMenu {#header-config-ios-titlemenu}
</PlatformHeading>

```ts
titleMenu?: StackHeaderMenuIOS;
```

Menu definition for the title context menu.

Configures a dropdown menu attached to the navigation bar title area.
Works independently of [titleItem](#header-config-ios-titleitem); the menu appears for both
plain text and custom view title.

**Type:** [`StackHeaderMenuIOS`](#stackheadermenuios)

<PlatformHeading platforms={[{"platform":"ios","from":"13"}]}>
#### ios.trailingItems {#header-config-ios-trailingitems}
</PlatformHeading>

```ts
trailingItems?: StackHeaderItemIOS[];
```

A list of items placed starting from the trailing edge.

If there is not enough space to fit some items, they are moved to the overflow menu, one by one.

Note: Custom items are not put into the overflow menu, but are removed entirely.

**Type:** [`StackHeaderItemIOS[]`](#stackheaderitemios)
