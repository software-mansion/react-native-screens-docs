#### android.contentInsetStart {#header-config-android-contentinsetstart}
</ReferenceHeading>

```ts
contentInsetStart?: number;
```

Start inset of the toolbar content area.

The inset is a minimum: the navigation icon is positioned before it is
applied and is not bounded by it, so the content area starts at whichever
reaches further from the edge — the navigation icon's trailing edge or this
inset. A back button usually wins, which makes this prop inert while one is
visible.

Applies to all header types. On `'medium'` / `'large'` it affects the
collapsed title only.

By default, the native platform applies a non-zero inset which makes a
centered collapsed title look off-center when `collapsedTitleGravityMode:
'availableSpace'` is used.

**Default:** Material's default inset is used.

#### android.liftOnScroll {#header-config-android-liftonscroll}
</ReferenceHeading>

```ts
liftOnScroll?: boolean;
```

Whether the app bar lifts (applies a tonal/elevation shift) when
content is scrolled beneath it.

For reliable behavior the content scroll view should be designated with a
`ScrollViewMarker`. Without it, the app bar cannot always locate the scroll
view, which can cause the lifted state to flicker while scrolling.

Applies to the `'small'` header only. For `'medium'` and `'large'`
headers the Material `CollapsingToolbarLayout` uses a fade title-collapse
mode that installs its own content scrim and disables the app bar's
lift-on-scroll, so this prop has no effect there. The collapsed appearance
of those headers is instead controlled by that content scrim, which is not
exposed yet.

Has no effect while the header is `transparent` (there is no scrolling
content behavior installed in that mode).

**Default:** `true`

Maximum number of lines for the expanded title and subtitle.

#### android.scrollFlagExitUntilCollapsed {#header-config-android-scrollflagexituntilcollapsed}
</ReferenceHeading>

```ts
scrollFlagExitUntilCollapsed?: boolean;
```

When enabled, the header collapses only until its minimum height
(the toolbar) remains pinned at the top. Without this flag, the entire
header scrolls off the screen. Requires `scrollFlagScroll`.

When `undefined`, falls back to the type-specific default:
- `'small'` -\> `false`
- `'medium'` / `'large'` -\> `true`

Setting this flag for `'small'` header is equivalent to disabling
