## InterfaceOrientation {#interfaceorientation}

> **InterfaceOrientation** = `"all"` \| `"allButUpsideDown"` \| `"portrait"` \| `"portraitUp"` \| `"portraitDown"` \| `"landscape"` \| `"landscapeLeft"` \| `"landscapeRight"`

Defined in: [components/shared/types.ts:81](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/shared/types.ts#L81)

Set of interface orientations a container supports.

The following values are supported:
- `'all'` — all orientations.
- `'allButUpsideDown'` — all orientations except portrait upside-down.
- `'portrait'` — portrait orientations.
- `'portraitUp'` — upright portrait.
- `'portraitDown'` — upside-down portrait.
- `'landscape'` — landscape orientations.
- `'landscapeLeft'` — landscape, rotated left.
- `'landscapeRight'` — landscape, rotated right.
