Icon descriptor for an iOS component.

The following variants are supported:
- [PlatformIconIOSSfSymbol](#platformiconiossfsymbol) — an SF Symbol by name.
- [PlatformIconIOSXcasset](#platformiconiosxcasset) — an asset-catalog image by name.
- [PlatformIconIOSTemplate](#platformiconiostemplate) — a template image source.
- [PlatformIconShared](#platformiconshared) — a React Native image source.
