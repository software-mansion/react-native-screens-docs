#### PlatformIconAndroid {#platformiconandroid}
</ReferenceHeading>

```ts
type PlatformIconAndroid = PlatformIconAndroidDrawableResource | PlatformIconShared;
```

Icon of a native element on Android, such as a header item.

The `type` field selects the kind of the icon. The following kinds are
supported:
- [PlatformIconAndroidDrawableResource](#platformiconandroiddrawableresource) — a drawable resource.
- [PlatformIconShared](#platformiconshared) — an image source.

**Type:** [`PlatformIconAndroidDrawableResource`](#platformiconandroiddrawableresource) \| [`PlatformIconShared`](#platformiconshared)
