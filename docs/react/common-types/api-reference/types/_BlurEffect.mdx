#### BlurEffect {#blureffect}
</ReferenceHeading>

```ts
type BlurEffect =
  | "none"
  | "extraLight"
  | "light"
  | "dark"
  | "regular"
  | "prominent"
  | "systemUltraThinMaterial"
  | "systemThinMaterial"
  | "systemMaterial"
  | "systemThickMaterial"
  | "systemChromeMaterial"
  | "systemUltraThinMaterialLight"
  | "systemThinMaterialLight"

  | "systemMaterialDark"

  | "systemChromeMaterialDark";
```

Blur effect applied to the background of a native view.

`'none'` disables the blur effect. Every other value is the UIKit
`UIBlurEffect.Style` of the same name; see the UIKit documentation for how
each one looks. The following values are supported:
- `'none'`
- `'extraLight'`
- `'light'`
- `'dark'`
- `'regular'`
- `'prominent'`
- `'systemUltraThinMaterial'`
- `'systemThinMaterial'`
- `'systemMaterial'`
- `'systemThickMaterial'`
- `'systemChromeMaterial'`
- `'systemUltraThinMaterialLight'`
- `'systemThinMaterialLight'`
- `'systemMaterialLight'`
- `'systemThickMaterialLight'`
- `'systemChromeMaterialLight'`
- `'systemUltraThinMaterialDark'`
- `'systemThinMaterialDark'`
- `'systemMaterialDark'`
- `'systemThickMaterialDark'`
- `'systemChromeMaterialDark'`

**See:** [UIBlurEffect.Style](https://developer.apple.com/documentation/uikit/uiblureffect/style)
