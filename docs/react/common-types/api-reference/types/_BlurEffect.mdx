#### BlurEffect {#blureffect}
</ReferenceHeading>

```ts
type BlurEffect = "none" | BlurEffectStyle;
```

Blur effect applied to the background of a native view.

Accepts any [BlurEffectStyle](#blureffectstyle) value, plus:
- `'none'` — disables the blur effect.

**Type:** `"none"` \| [`BlurEffectStyle`](#blureffectstyle)

**See:** [UIBlurEffect.Style](https://developer.apple.com/documentation/uikit/uiblureffect/style)
