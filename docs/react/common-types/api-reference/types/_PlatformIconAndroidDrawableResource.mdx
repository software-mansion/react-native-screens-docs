#### PlatformIconAndroidDrawableResource {#platformiconandroiddrawableresource}
</ReferenceHeading>

Icon loaded from an Android drawable resource.

The resource is looked up by name among the drawables of the app first and
then among the drawables of the Android system.

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/shared/types.ts#L191"}>
##### name {#platformiconandroiddrawableresource-name}
</ReferenceHeading>

```ts
name: string;
```

Name of the drawable resource, without the file extension.

**Example:** For `res/drawable/ic_search.xml`: ```tsx { type: 'drawableResource', name: 'ic_search' } ```

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/shared/types.ts#L181"}>
##### type {#platformiconandroiddrawableresource-type}
</ReferenceHeading>

```ts
type: "drawableResource";
```

Kind of the icon.
