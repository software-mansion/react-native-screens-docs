#### PlatformIconImageRenderingModeIOS {#platformiconimagerenderingmodeios}
</ReferenceHeading>

```ts
type PlatformIconImageRenderingModeIOS = "default" | "template" | "original";
```

How an image icon is rendered on iOS.

The following values are supported:
- `'default'` — the default of the element that shows the icon.
- `'template'` — the image is used as a template image: its shape is drawn
  in the icon color of the element.
- `'original'` — the image keeps its own colors.

**See:** [UIImage.RenderingMode](https://developer.apple.com/documentation/uikit/uiimage/renderingmode-swift.enum)
