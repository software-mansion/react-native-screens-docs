#### PlatformIconIOSTemplate {#platformiconiostemplate}
</ReferenceHeading>

Icon loaded from an image source and rendered as a template image.

The colors of the image are ignored and only its alpha channel is used, so
the icon is drawn in the current tint color.

**See:** [UIImage.RenderingMode.alwaysTemplate](https://developer.apple.com/documentation/uikit/uiimage/renderingmode/alwaystemplate)

<ReferenceHeading source={"https://github.com/software-mansion/react-native-screens/blob/main/src/components/shared/types.ts#L213"}>
##### templateSource {#platformiconiostemplate-templatesource}
</ReferenceHeading>

```ts
templateSource: ImageSource;
```

Image source the icon is loaded from.

**See:** [React Native: ImageSource](https://reactnative.dev/docs/image#imagesource)
