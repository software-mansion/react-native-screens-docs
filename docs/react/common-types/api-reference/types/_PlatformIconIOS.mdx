#### PlatformIconIOS {#platformiconios}
</ReferenceHeading>

```ts
type PlatformIconIOS =
  | PlatformIconIOSSfSymbol
  | PlatformIconIOSXcasset
  | PlatformIconIOSTemplate
  | PlatformIconShared;
```

Icon of a native element on iOS, such as a header item.

The `type` field selects the kind of the icon. The following kinds are
supported:
- [PlatformIconIOSSfSymbol](#platformiconiossfsymbol) — an SF Symbol.
- [PlatformIconIOSXcasset](#platformiconiosxcasset) — an image from the app's asset catalog.
- [PlatformIconIOSTemplate](#platformiconiostemplate) — an image source rendered as a template
  image.
- [PlatformIconShared](#platformiconshared) — an image source.

**Type:** [`PlatformIconIOSSfSymbol`](#platformiconiossfsymbol) \| [`PlatformIconIOSXcasset`](#platformiconiosxcasset) \| [`PlatformIconIOSTemplate`](#platformiconiostemplate) \| [`PlatformIconShared`](#platformiconshared)
