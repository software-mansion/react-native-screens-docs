#### UserInterfaceStyle {#userinterfacestyle}
</ReferenceHeading>

```ts
type UserInterfaceStyle = "unspecified" | "light" | "dark";
```

Interface style of a native view.

The following values are supported:
- `'unspecified'` — an unspecified interface style; the style of the parent
  is used.
- `'light'` — the light interface style.
- `'dark'` — the dark interface style.

**See:** [UIUserInterfaceStyle](https://developer.apple.com/documentation/uikit/uiuserinterfacestyle)
