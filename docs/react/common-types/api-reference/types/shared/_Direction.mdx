## Direction {#direction}

> **Direction** = `"ltr"` \| `"rtl"`

Defined in: [components/shared/types.ts:59](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/shared/types.ts#L59)

Layout direction of a container and its content.

The following values are supported:
- `'ltr'` — force a left-to-right layout direction.
- `'rtl'` — force a right-to-left layout direction.

**Platform:** android \>= 21, ios \>= 13
