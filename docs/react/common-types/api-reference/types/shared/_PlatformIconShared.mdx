## PlatformIconShared {#platformiconshared}

```ts
type PlatformIconShared = {
  imageSource: ImageSourcePropType;
  type: "imageSource";
};
```

Icon backed by a React Native image source, shared across platforms.

Discriminated by `type: 'imageSource'`.

**Platform:** android \>= 21, ios \>= 13

### Properties

#### imageSource {#platformiconshared-imagesource}

```ts
imageSource: ImageSourcePropType;
```

The image to render, in any form `Image`'s `source` accepts.

**Platform:** android \>= 21, ios \>= 13

#### type {#platformiconshared-type}

```ts
type: "imageSource";
```

Discriminant selecting the image-source variant.

**Platform:** android \>= 21, ios \>= 13
