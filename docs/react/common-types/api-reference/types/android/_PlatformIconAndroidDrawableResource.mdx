## PlatformIconAndroidDrawableResource {#platformiconandroiddrawableresource}

```ts
type PlatformIconAndroidDrawableResource = {
  name: string;
  type: "drawableResource";
};
```

Icon backed by an Android drawable resource, referenced by `name`.

Discriminated by `type: 'drawableResource'`.

**Platform:** android \>= 21

### Properties

#### name {#platformiconandroiddrawableresource-name}

```ts
name: string;
```

Name of the drawable resource, without the extension or the `@drawable/` prefix.

**Platform:** android \>= 21

#### type {#platformiconandroiddrawableresource-type}

```ts
type: "drawableResource";
```

Discriminant selecting the drawable-resource variant.

**Platform:** android \>= 21
