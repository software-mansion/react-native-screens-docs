## PlatformIconAndroidDrawableResource {#platformiconandroiddrawableresource}
</PlatformHeading>

```ts
type PlatformIconAndroidDrawableResource = {
  name: string;
  type: "drawableResource";
};
```

Icon backed by an Android drawable resource, referenced by `name`.

Discriminated by `type: 'drawableResource'`.
