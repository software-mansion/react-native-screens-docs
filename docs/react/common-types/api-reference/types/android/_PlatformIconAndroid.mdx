## PlatformIconAndroid {#platformiconandroid}
</PlatformHeading>

```ts
type PlatformIconAndroid = PlatformIconAndroidDrawableResource | PlatformIconShared;
```

Icon descriptor for an Android component.

The following variants are supported:
- [PlatformIconAndroidDrawableResource](#platformiconandroiddrawableresource) — a drawable resource by name.
- [PlatformIconShared](#platformiconshared) — a React Native image source.

**Type:** [`PlatformIconAndroidDrawableResource`](#platformiconandroiddrawableresource) \| [`PlatformIconShared`](#platformiconshared)
