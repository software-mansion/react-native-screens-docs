## ScrollEdgeEffect {#scrolledgeeffect}
</PlatformHeading>

```ts
type ScrollEdgeEffect = "automatic" | "hard" | "soft" | "hidden";
```

Visual effect applied at a scrollable edge.

The following values are supported:
- `'automatic'` — the system default effect for the edge.
- `'hard'` — a hard cut-off effect.
- `'soft'` — a soft, fading effect.
- `'hidden'` — no edge effect.
