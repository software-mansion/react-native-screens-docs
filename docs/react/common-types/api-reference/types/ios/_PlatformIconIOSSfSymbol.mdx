## PlatformIconIOSSfSymbol {#platformiconiossfsymbol}

```ts
type PlatformIconIOSSfSymbol = {
  name: string;
  type: "sfSymbol";
};
```

Icon backed by an SF Symbol, referenced by `name`.

Discriminated by `type: 'sfSymbol'`.

**Platform:** ios \>= 13

### Properties

#### name {#platformiconiossfsymbol-name}

```ts
name: string;
```

Name of the SF Symbol, as listed in Apple's SF Symbols app (e.g. `'star.fill'`).

**Platform:** ios \>= 13

#### type {#platformiconiossfsymbol-type}

```ts
type: "sfSymbol";
```

Discriminant selecting the SF Symbol variant.

**Platform:** ios \>= 13
