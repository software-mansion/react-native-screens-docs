## PlatformIconIOSTemplate {#platformiconiostemplate}

```ts
type PlatformIconIOSTemplate = {
  templateSource: ImageSourcePropType;
  type: "templateSource";
};
```

Icon backed by a template image source, rendered with the component's tint.

Discriminated by `type: 'templateSource'`.

**Platform:** ios \>= 13

### Properties

#### templateSource {#platformiconiostemplate-templatesource}

```ts
templateSource: ImageSourcePropType;
```

The image to render as a template, in any form `Image`'s `source` accepts. Its
shape is used as a mask; the color comes from the component's tint.

**Platform:** ios \>= 13

#### type {#platformiconiostemplate-type}

```ts
type: "templateSource";
```

Discriminant selecting the template-image variant.

**Platform:** ios \>= 13
