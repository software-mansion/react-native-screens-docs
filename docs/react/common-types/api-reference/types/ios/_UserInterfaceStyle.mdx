### UserInterfaceStyle {#userinterfacestyle}
</ReferenceHeading>

```ts
type UserInterfaceStyle = "unspecified" | "light" | "dark";
```

Interface style, including an unspecified (inherited) option.

The following values are supported:
- `'unspecified'` — no explicit style; inherit from the system / parent.
- `'light'` — the light interface style.
- `'dark'` — the dark interface style.
