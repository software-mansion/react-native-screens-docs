#### ColorScheme {#colorscheme}
</ReferenceHeading>

```ts
type ColorScheme = "light" | "dark";
```

Color scheme of a container and its child containers.

The following values are supported:
- `'light'` — the light interface style.
- `'dark'` — the dark interface style.
