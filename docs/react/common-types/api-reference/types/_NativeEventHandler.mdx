#### NativeEventHandler {#nativeeventhandler}
</ReferenceHeading>

```ts
type NativeEventHandler<T> = (event: NativeSyntheticEvent<T>) => void;
```

Handler of a native event.

**Type Parameters:**

- `T` — Payload the native event carries.

**Parameters:**

- `event`: `NativeSyntheticEvent`\<`T`\> — The native event, with the payload in `event.nativeEvent`.

**Returns:** `void`
