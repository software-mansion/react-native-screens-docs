BlurEffect​

BlurEffect = "none" | "extraLight" | "light" | "dark" | "regular" | "prominent" | "systemUltraThinMaterial" | "systemThinMaterial" | "systemMaterial" | "systemThickMaterial" | "systemChromeMaterial" | "systemUltraThinMaterialLight" | "systemThinMaterialLight" | "systemMaterialLight" | "systemThickMaterialLight" | "systemChromeMaterialLight" | "systemUltraThinMaterialDark" | "systemThinMaterialDark" | "systemMaterialDark" | "systemThickMaterialDark" | "systemChromeMaterialDark"

Defined in: components/shared/types.ts:18

Blur effect style applied to a material background.

Remarks​

Each value maps to a UIKit UIBlurEffect.Style of the same name. The following values are supported: 'none', 'extraLight', 'light', 'dark', 'regular', 'prominent', 'systemUltraThinMaterial', 'systemThinMaterial', 'systemMaterial', 'systemThickMaterial', 'systemChromeMaterial', and their explicit Light / Dark variants (e.g. 'systemMaterialLight', 'systemMaterialDark').

Platform​

ios

Since​

5.0

UIBlurEffect.Style

InterfaceOrientation​

InterfaceOrientation = "all" | "allButUpsideDown" | "portrait" | "portraitUp" | "portraitDown" | "landscape" | "landscapeLeft" | "landscapeRight"

Defined in: components/shared/types.ts:81

Set of interface orientations a container supports.

The following values are supported:

  • 'all' — all orientations.
  • 'allButUpsideDown' — all orientations except portrait upside-down.
  • 'portrait' — portrait orientations.
  • 'portraitUp' — upright portrait.
  • 'portraitDown' — upside-down portrait.
  • 'landscape' — landscape orientations.
  • 'landscapeLeft' — landscape, rotated left.
  • 'landscapeRight' — landscape, rotated right.

Platform​

ios

Since​

5.0

ScrollEdgeEffect​

ScrollEdgeEffect = "automatic" | "hard" | "soft" | "hidden"

Defined in: components/shared/types.ts:103

Visual effect applied at a scrollable edge.

The following values are supported:

  • 'automatic' — the system default effect for the edge.
  • 'hard' — a hard cut-off effect.
  • 'soft' — a soft, fading effect.
  • 'hidden' — no edge effect.

Platform​

ios

Since​

5.0

UserInterfaceStyle = "unspecified" | "light" | "dark"
