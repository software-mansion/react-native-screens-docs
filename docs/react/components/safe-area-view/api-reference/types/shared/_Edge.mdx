#### Edge {#edge}
</ReferenceHeading>

```ts
type Edge = "top" | "right" | "bottom" | "left";
```

A view edge that a safe-area inset can be applied to.

The following values are supported:
- `'top'` — the top edge.
- `'right'` — the right edge.
- `'bottom'` — the bottom edge.
- `'left'` — the left edge.
