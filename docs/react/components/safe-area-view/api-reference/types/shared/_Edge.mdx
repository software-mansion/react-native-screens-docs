## Edge {#edge}

> **Edge** = `"top"` \| `"right"` \| `"bottom"` \| `"left"`

Defined in: [components/safe-area/SafeAreaView.types.ts:16](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/safe-area/SafeAreaView.types.ts#L16)

A view edge that a safe-area inset can be applied to.

The following values are supported:
- `'top'` — the top edge.
- `'right'` — the right edge.
- `'bottom'` — the bottom edge.
- `'left'` — the left edge.

**Platform:** android \>= 21, ios \>= 13
