## InsetType {#insettype}

> **InsetType** = `"all"` \| `"system"` \| `"interface"`

Defined in: [components/safe-area/SafeAreaView.types.ts:30](https://github.com/software-mansion/react-native-screens/blob/8de39c66b032cbe0b0997f370555ded4ff950eab/src/components/safe-area/SafeAreaView.types.ts#L30)

Set of insets used to compute the safe area on Android.

The following values are supported:
- `'all'` — use all insets.
- `'system'` — use system insets.
- `'interface'` — use interface insets.

android
