#### InsetType {#insettype}
</PlatformHeading>

```ts
type InsetType = "all" | "system" | "interface";
```

Set of insets used to compute the safe area on Android.

The following values are supported:
- `'all'` — use all insets.
- `'system'` — use system insets.
- `'interface'` — use interface insets.
