#### FormSheetBackgroundEffect {#formsheetbackgroundeffect}
</ReferenceHeading>

```ts
type FormSheetBackgroundEffect =
  | "automatic"
  | "none"
  | FormSheetBackgroundEffectColor
  | FormSheetBackgroundEffectBlur;
```

Material the system renders behind the sheet's content.

The following values are supported:
- `'automatic'` — the system's default material for sheets.
- `'none'` — no material at all; the sheet is transparent and only its
  content is drawn.
- [FormSheetBackgroundEffectColor](#formsheetbackgroundeffectcolor) — a flat fill of the given color.
- [FormSheetBackgroundEffectBlur](#formsheetbackgroundeffectblur) — a blur of the given style.

**Type:** `"automatic"` \| `"none"` \| [`FormSheetBackgroundEffectColor`](#formsheetbackgroundeffectcolor) \| [`FormSheetBackgroundEffectBlur`](#formsheetbackgroundeffectblur)
