#### FormSheetPreferredCornerRadius {#formsheetpreferredcornerradius}
</ReferenceHeading>

```ts
type FormSheetPreferredCornerRadius = number | "systemDefault";
```

Corner radius of a sheet.

The following values are supported:
- a number — the radius in density-independent pixels.
- `'systemDefault'` — the system's default corner radius.
