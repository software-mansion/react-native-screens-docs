## FormSheetEventHandler {#formsheeteventhandler}

```ts
type FormSheetEventHandler<T> = (e: NativeSyntheticEvent<T>) => void;
```

Handler for a form sheet native synthetic event.

**Platform:** android \>= 21, ios \>= 13

**Type Parameters:**

- `T` — Payload the native event carries.

**Parameters:**

- `e`: `NativeSyntheticEvent`\<`T`\> — The native synthetic event.

**Returns:** `void`
