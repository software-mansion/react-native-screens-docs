Workaround component for a `react-native` scroll-to-top issue on iOS.

This component is meant to be used only as a temporary workaround until the
issue is fixed on `react-native`'s side — see the
[issue report](https://github.com/facebook/react-native/issues/56061).

Falls back to `React.Fragment` on platforms other than iOS.

**Platform:** ios \>= 13
