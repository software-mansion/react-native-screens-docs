# TabsScreenPropsIOS

Used by [`Tabs.Screen`](../TabsScreen).

## Fields

<Badges platforms={['ios']}>
### experimental_userInterfaceStyle
</Badges>

Allows to override system appearance for the tab bar.

```ts
experimental_userInterfaceStyle?: UserInterfaceStyle;
```

Dynamic changes to the prop value for the currently visible screen are not supported.

:::warning
Please note that this prop is marked as **experimental** and might be subject to breaking changes or even removal.
Consider using `colorScheme` on `TabsHost` instead.
:::

The following values are currently supported:
- `unspecified` - an unspecified interface style,
- `light` - the light interface style,
- `dark` - the dark interface style.

The supported values correspond to the official UIKit documentation for [`UIUserInterfaceStyle`](https://developer.apple.com/documentation/uikit/uiuserinterfacestyle).

**Default:** `unspecified`

<Badges platforms={['ios']}>
### icon
</Badges>

Specifies the icon for the tab bar item.

```ts
icon?: PlatformIconIOS;
```

Supported values:
- `{ type: 'imageSource', imageSource }`
  Uses an image from the provided resource.
- `{ type: 'sfSymbol', name }`
  Uses an SF Symbol with the specified name.
- `{ type: 'xcasset', name }`
  Uses asset from Xcassets.
- `{ type: 'templateSource', templateSource }`
  Uses the provided image as a template image.
  The icon color will depend on the current state
  of the tab bar item and icon color-related props.

If no [`selectedIcon`](#selectedicon) is provided, this icon will also
be used as the selected state icon.

<Badges platforms={['ios']}>
### overrideScrollViewContentInsetAdjustmentBehavior
</Badges>

Specifies if `contentInsetAdjustmentBehavior` of first ScrollView
in first descendant chain from tab screen should be overridden back from `never`
to `automatic`.

```ts
overrideScrollViewContentInsetAdjustmentBehavior?: boolean;
```

By default, `react-native`'s ScrollView has `contentInsetAdjustmentBehavior`
set to `never` instead of UIKit-default (which is `automatic`). This
prevents ScrollViews from respecting navigation bar insets.
When this prop is set to `true`, `automatic` behavior is reverted.

**Default:** `true`

<Badges platforms={['ios']}>
### scrollEdgeAppearance
</Badges>

Specifies the tab bar appearace when edge of scrollable content aligns
with the edge of the tab bar.

```ts
scrollEdgeAppearance?: TabsScreenAppearanceIOS;
```

This prop allows to customize the appearance depending on the tab bar item layout (`stacked`,
`inline`, `compact inline`) and state (`normal`, `selected`, `focused`, `disabled`).

:::note
If this property is `undefined`, UIKit uses `standardAppearance`, modified to
have a transparent background.
:::

See [`TabsScreenAppearanceIOS`](./TabsScreenAppearanceIOS) for full type definition.

<Badges platforms={['ios']}>
### selectedIcon
</Badges>

Specifies the icon for tab bar item when it is selected.

```ts
selectedIcon?: PlatformIconIOS;
```

Supports the same values as `icon` property.

To use `selectedIcon`, [`icon`](#icon) must also be provided.

### standardAppearance
</Badges>

Specifies the standard tab bar appearance.

```ts
standardAppearance?: TabsScreenAppearanceIOS;
```

This prop allows to customize the appearance depending on the tab bar item layout (`stacked`,
`inline`, `compact inline`) and state (`normal`, `selected`, `focused`, `disabled`).

See [`TabsScreenAppearanceIOS`](./TabsScreenAppearanceIOS) for full type definition.

<Badges platforms={['ios']}>
### systemItem
</Badges>

System-provided tab bar item with predefined icon and title.

```ts
systemItem?: TabsScreenSystemItem;
```

Defines Apple's built-in tab bar items (e.g., bookmarks, contacts, downloads) with
standard iOS styling and localized titles. Custom `icon` or `selectedIcon`
properties will override the system icon, but the system-defined title cannot
be customized.

See [`UITabBarItem.SystemItem`](https://developer.apple.com/documentation/uikit/uitabbaritem/systemitem) for full reference.
