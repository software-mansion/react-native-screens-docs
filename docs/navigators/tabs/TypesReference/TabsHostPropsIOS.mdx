# TabsHostPropsIOS

Used by [`Tabs.Host`](../TabsHost).

## Fields

<Badges platforms={['ios']}>
### bottomAccessory
</Badges>

Specifies component used as bottom accessory.

```ts
bottomAccessory?: TabsBottomAccessoryComponentFactory;
```

This prop is a function that accepts `environment` as a parameter and returns
the component that will be rendered in the bottom accessory.

`environment` can be one of the following values:

- `regular` - the accessory is laid out above the bottom tab bar,
- `inline` - the accessory is laid out inline with the collapsed bottom
  tab bar.

If this prop is `undefined`, the bottom accessory will not be rendered.

:::note
To allow accessory rendering based on environment, component is rendered 2 times
for both `regular` and `inline` environments at the same time.
Environment determines which component is visible at given moment.
This might require implementing a solution to share state between both rendered
components (e.g. usage of context).
:::

**Supported:** iOS 26 or higher

<Badges platforms={['ios']}>
### onMoreTabSelected
</Badges>

A callback that gets invoked when the user taps the "More" tab bar item.

```ts
onMoreTabSelected?: (event: NativeSyntheticEvent<MoreTabSelectedEvent>) => void;
```

This event fires when the user taps the system-generated "More" tab bar item.
It does NOT fire when a tab is selected from within the More list — that triggers
the normal `onTabSelected` event instead.

See [`MoreTabSelectedEvent`](./MoreTabSelectedEvent).

<Badges platforms={['ios']}>
### tabBarControllerMode
</Badges>

Specifies the display mode for the tab bar.

```ts
tabBarControllerMode?: TabBarControllerMode;
```

The following values are currently supported:

- `automatic` - the system sets the display mode based on the tab’s content
- `tabBar` - the system displays the content only as a tab bar
- `tabSidebar` - the tab bar is displayed as a sidebar

See the official documentation in Apple docs for [`UITabBarController.Mode`](https://developer.apple.com/documentation/uikit/uitabbarcontroller/mode) for details.

**Default:** `automatic`.

**Supported:** iOS 18 or higher, no support on TVOS

---

<Badges platforms={['ios']}>
### tabBarMinimizeBehavior
</Badges>

Specifies the minimize behavior for the tab bar.

```ts
tabBarMinimizeBehavior?: TabBarMinimizeBehavior;
```

The following values are currently supported:

- `automatic` - resolves to the system default minimize behavior
- `never` - the tab bar does not minimize
- `onScrollDown` - the tab bar minimizes when scrolling down and
  expands when scrolling back up
- `onScrollUp` - the tab bar minimizes when scrolling up and expands
  when scrolling back down

The supported values correspond to the official UIKit documentation for [`UITabBarController.MinimizeBehavior`](https://developer.apple.com/documentation/uikit/uitabbarcontroller/minimizebehavior).

**Default:** `automatic`.

**Supported:** iOS 26 or higher

<Badges platforms={['ios']}>
### tabBarTintColor
</Badges>

Specifies the color used for selected tab's text and icon color.

```ts
tabBarTintColor?: ColorValue;
```

Starting from iOS 26, this prop also impacts glow of Liquid Glass tab
selection view.

[`tabBarItemTitleFontColor`](./TabsScreenItemStateAppearanceIOS#tabbaritemtitlefontcolor) and [`tabBarItemIconColor`](./TabsScreenItemStateAppearanceIOS#tabbaritemiconcolor) defined on
`Tabs.Screen` component override this color.
