# TabSelectionPreventedEvent

Used by [`Tabs.Host.onTabSelectionPrevented`](../TabsHost#ontabselectionprevented).

Payload of the event emitted when the native side prevents a tab selection
because the target screen has `preventNativeSelection` enabled.
