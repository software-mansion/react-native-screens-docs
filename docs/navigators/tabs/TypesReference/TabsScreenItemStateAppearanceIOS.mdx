<Badges platforms={['ios']}>
### tabBarItemIconColor
</Badges>

Specifies the icon color for each tab bar item when tab screen
is selected.

```ts
tabBarItemIconColor?: ColorValue;
```

This also impacts the title text color.

Starting from iOS 26, it only applies to selected tab bar item. Other items
adopt a dark or light appearance depending on the theme of the tab bar.

Is overridden by [`tabBarItemTitleFontColor`](#tabbaritemtitlefontcolor) (for title text color).
Overrides [`tabBarTintColor`](./TabsHostPropsIOS#tabbartintcolor).

---

### tabBarItemTitleFontColor
</Badges>

<Badges platforms={['ios']}>
### tabBarItemTitlePositionAdjustment
</Badges>

Specifies the title offset for each tab bar item when tab screen
is selected.

```ts
tabBarItemTitlePositionAdjustment?: {
  horizontal?: number;
  vertical?: number;
};
```

Depending on the iOS version and the device's interface orientation,
this setting may affect the alignment of the text, badge and icon.
