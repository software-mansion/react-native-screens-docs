# TabsScreenAppearanceIOS

Used by [`TabsScreenPropsIOS`](./TabsScreenPropsIOS).

## Fields

<Badges platforms={['ios']}>
### compactInline
</Badges>

Specifies the appearance of tab bar items when they are in compact inline layout.

```ts
compactInline?: TabsScreenItemAppearanceIOS;
```

Tab bar items in compact inline layout have the icon next to the title.
Compact inline layout is used in compact-width environments, e.g. in landscape orientation on iPhone.

Complete list of size classes for iOS and iPadOS devices is available in Apple's Human Interface Guidelines.

See [`TabsScreenItemAppearanceIOS`](./TabsScreenItemAppearanceIOS) for full type definition.

<Badges platforms={['ios']}>
### tabBarBlurEffect
</Badges>

Specifies the blur effect applied to the tab bar when tab screen is selected.

```ts
tabBarBlurEffect?: TabsScreenBlurEffect;
```

Works with [`tabBarBackgroundColor`](#tabbarbackgroundcolor) with alpha &lt; 1.

The following values are currently supported:
- `none` - disables blur effect
- `systemDefault` - uses UIKit's default tab bar blur effect
- one of styles mapped from UIKit's UIBlurEffectStyle, e.g. `systemUltraThinMaterial`

Complete list of possible blur effect styles is available in the official UIKit documentation for [`UIBlurEffect.Style`](https://developer.apple.com/documentation/uikit/uiblureffect/style).

This property does not affect the tab bar starting from iOS 26.

**Default:** `systemDefault`

**Supported:** iOS 18 or lower
