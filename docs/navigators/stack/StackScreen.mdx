# Stack.Screen

Represents a single screen in the stack. Each screen must have a unique `screenKey`. The `activityMode` controls whether the screen remains attached to the view hierarchy when inactive.

## Props

### activityMode

```ts
activityMode: StackScreenActivityMode;
```
